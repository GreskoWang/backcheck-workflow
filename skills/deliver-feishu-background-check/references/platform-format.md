# 十四平台成品格式

### 十四个平台章节

每个主体必须且只能出现一次以下章节，名称和顺序不变：`微博`、`B站`、`抖音`、`小红书`、`知乎`、`网易云音乐`、`贴吧`、`豆瓣`、`境内其他内容`、`X`、`Facebook`、`INS`、`油管`、`境外其他网站`。不得删除、改名、重排或跳过。

已确认删除、封禁、关闭、隐私页面、限制查看等客观原因不可访问的项目，按[访问结项规则](../../background-check-research/references/access-policy.md#客观不可访问项按无问题结项)记“无问题”。这是已结项的业务状态，不另写“待恢复／尚未完成”模块，不因无法取得该项内容阻止交付；实际原因保留在既有任务状态，不能伪称读过不可见内容。已有可核实风险和其他可访问待查内容分别按真实情况处理。

新增境内平台放“境内其他内容”，境外平台放“境外其他网站”，并如实标明子平台。十四章保持连续有序列表。所有可见正文或子平台前缀按实际顺序生成全角 `（1）` 至 `（N）`，不得使用 `1.`、`2.` 或复制同一前缀；每个“其他”章的具名列表从 `（1）` 重新开始。

十四平台标题必须使用飞书原生有序列表，首项 `sequence=1`、其余 `sequence=auto`，在页面实显中确认自动连续显示 `1. 微博` 至 `14. 境外其他网站`。此要求适用于单人报告、团队合并及原样回填，不得用手写编号的普通文本替代。回读字段缺失或页面重复显示 `1.` 时，继续核对并修复原生列表结构，再确认实显；接口成功或手写编号看似连续均不能代替验收。首次终审或列表结构变化时必须做一次页面实显检查；仅正文文字变化且布局指纹不变时复用已验证原生列表及连续编号的视觉 PASS，不重复截整页。

“其他”章最后一个具名条目后，分别添加不编号的精确尾句；没有额外具名平台时，尾句紧随百度／谷歌搜索模块：

- `其他境内平台暂未发现相关账号或相关内容的负面及敏感信息。`
- `其他境外平台暂未发现相关账号或相关内容的负面及敏感信息。`

### 十四个平台逐项交付标准

### 结论与证据一致性（优先适用）

每个模块先判定实际状态，再选择下方该平台的固定句。以下条件优先于示例、旧记忆及笼统的“无风险”输入：

- **无相关结果**：有效搜索确实没有主体相关结果。空白页面、登录框架、验证失败、读取截断不能支持该结论。
- **有相关结果且已查未见问题**：包括作品转载、署名提及和正常讨论；使用该平台的无问题句，不能使用任何“无相关内容／无涉及内容”句。
- **有风险**：按已确认归属分别写事实、截图和来源，不能把第三方转载内容当作本人发言。
- **尚未完成**：仅用于仍有应执行动作的项目，不包括已确认客观不可访问并按“无问题”结项的项目。只在内部阶段记录写明具体缺口并继续调查；交付终稿不得包含“尚未完成”等字样或新增未闭环模块；不能仅留空让读者误以为没有内容，也不能写成上述任何完成结论。此规则只改变该模块的结论，不增加或重排十四平台模块。

外部搜索引擎 `site:` 查询的零结果只覆盖其当前公开索引，不支持“平台无相关内容”或“无个人主页”。有署名转载但没有需记录问题时，必须选择“有相关结果且已查未见问题”，不得套用下面任何无内容的缺省句。

每次回读同时核对文字含义和来源，不仅核对格式。发现结论与实际结果矛盾就修正，并检查其他平台是否存在相同错误。

该章节中：
a. “风险点”指调查 Skill 已经记录、需要上游注意的公开现象或主题，如转发疑似台独言论、转发涉及敏感时政的内容、转发辱华动画《我的英雄学院》相关内容等等（仅作格式示例）。交付 Skill 不重新判断主体价值或决定是否合作。
b. “风险项”指每个风险点下的具体帖子、图片、视频、转发、点赞或第三方讨论。例如，在“转发英雄学院”风险点下，可以分别记录某日转发相关内容、为相关作品申辩等具体行为（仅作格式示例）。
c. 如果背调对象每个风险点只发现个例，则风险点就是风险项，汇总风险点时，按照风险项的写法直接汇报即可。
d. 第四章各平台模块中的“个人主页”“此人”等个人称谓，适用于个人主体；如果主体是组织、公司、品牌或项目，自动将其替换为“官方主页”或“项目主页”及对应的组织称谓，其他格式保持不变。
e. 每一个风险项固定按照 `一句话说明帖子内容 → 截图 → 完整可见的帖子链接` 的顺序填写。
f. 顶部“风险摘要”和“举例N”可以把跨平台的同类风险合并为一个风险组；十四个平台章节必须按平台分别展示，不得把其他平台的同类风险合并进当前平台的风险点。
g. 无风险平台的结论位置和措辞完全依照本文件后文该平台的逐项标准执行：规定“在链接后总结／写”时，结论必须与该链接处于同一文本区块，不得抽成独立结论块，也不得统一替换为“无问题”。平台主管全部模块结束后再放一个空白文本块，随后开始下一平台。主页和搜索 URL 的显示文字必须是完整 URL，链接目标必须与显示 URL 一致。
h. 主页 URL 的身份标签按调查结论填写。主确认账号沿用“个人主页／官方主页／项目主页”；只有调查结论明确标为小号时才使用“小号N”，其余追加确认主页写“个人主页N／官方主页N／项目主页N”。未确认账号写“疑似主页”，组织／公司／品牌写“疑似官方主页”，项目写“疑似项目主页”。本身份标签规则覆盖各平台关于“个人主页”和“小号”的默认示例，其他模块、顺序和措辞不变；禁止把疑似 URL 写成确认主页。
i. 如果模块只有一个疑似 URL，首行写为 `（1）疑似主页：[完整URL](完整URL)`；同平台有多个疑似 URL 时，按调查结论顺序写为 `（1）疑似主页1：……`、`疑似主页2：……`。如果已有确认主页，疑似 URL 放在确认 URL 之后，均不得写成“小号”。无风险时同一行追加本平台规定的干净结论；有风险时按本章顺序写风险点、截图和直接链接。额外平台写为 `（N）平台名疑似主页：[完整URL](完整URL)`。疑似主页的风险事实一律以“该疑似主页账号……”起句，顶部摘要和举例也必须保留“疑似主页”，不得抹去账号归属不确定性。
j. 用户明确提供的主页全部交付，不能因同平台数量删减；其中不能确认的全部使用疑似主页标签。每个实际平台最多再自动选择一个疑似主页，而且只在该平台没有用户提供疑似页时选择。内容很少的写疑似主页和“无问题”，领域不一致的写一句内容概括。其他同名噪音、候选排序和身份调试信息不进入飞书。普通姓名海量同名且没有可区分账号时，按本章正常“无主页”格式交付，不列候选清单。
k. 所有风险截图只保留账号归属、帖子文字或图片主体，以及证明转发／引用／点赞关系所需区域。必须裁掉浏览器标签栏、地址栏、书签栏、系统任务栏、通知、其他页签和无关内容；上传前再次检查隐私。

### 标题与举例区

单人报告使用 H3 `风险摘要`、H3 `基本信息`、H3 `背调详情` 和 H4 `举例N【风险标题】`，顶部标题不加主体名；用户指定其他层级时以用户指令为准。

顶部“风险摘要”和“举例N”的主题、数量和顺序必须一致。摘要高亮为无链接纯概述。每个举例按 `无链接H4标题 → 橙色图钉高亮块中带内部跳转的简短风险句 → 本主题全部入选事实及对应截图` 排列，不另加汇总“风险说明”链接框；不得只节选部分证据，也不因此扩大调查取样额度。

举例区不放外部 URL、“原帖”链接或图片下链接；唯一链接文本是图钉高亮句，并且必须指向该主题在正文中第一次出现的平台风险事实区块。

### 平台区块

平台风险必须在该平台章再次出现。每个风险项按 `一句话说明帖子内容 → 截图 → 独立完整纯文本帖子链接` 排列，不得写“同上”或“同B站”。风险项链接不设置富文本链接样式。

主页、关键词搜索和其他模块严格采用各平台逐项标准。上方“无风险可写话术总表”中的结论必须保留原词并直接追加在对应主页、话题或搜索 URL 后；不得抽成独立结论块，也不得跨平台统一措辞。平台主管末尾只保留一个空白文本块作为间隔。风险事实、截图和帖子链接各占一个区块。网易云音乐与INS不创建关键词搜索模块，贴吧不创建个人主页模块；其他平台按逐项标准保留其模块。“其他”章先放具名条目，再放精确尾句和间隔。访问故障和调查过程不写进成品；某个平台暂未完成时，在对应模块明确写“尚未完成”及具体缺口，不留容易被误读为空结果的占位，不写无主页、无搜索结果或其他干净结论，也不阻塞其他平台回填。

顶部“风险摘要”和“举例N”中，同一风险跨平台时可以合并为一个风险组并按平台标注证据；十四个平台章节中，各平台分别展示，不跨平台合并。截图根据数量、可读性和宽高比自适应排列，不固定列数。

### 基本信息与结果样式

“代表作”每部作品一个纯文本区块，不设置隐藏外链。基本信息网格内完整的 `背调对象：…`、`类别：…`、`简介：…` 区块均加粗。两个 50/50 网格的四列各只放一张中灰色 Callout，不加列级空白文本块；Callout 内只放字段正文，不放尾随空白子块。代表作 Callout 同样使用中灰背景，内部依次放 `代表作：` 和每部作品的独立文本块，不放尾随空白子块。四张基本信息卡图标默认依次为 `bust_in_silhouette`、`books`、`heart`、`ledger`，代表作图标为 `white_check_mark`；单份文档中用户认可的图标例外不变成通用模板。通过原生复制保留模板既有颜色和图标，再做页面目视检查；API省略颜色字段不等于背景缺失，不为补写参数重建卡片。代表作选取按[基本信息规则](feishu-style-guide.md#基本信息)执行。

“背调结果”保留按已核实风险性质判断的三级定级：“建议谨慎评估”（text_color:1）、“建议评估”（text_color:2）、“无合作风险”（默认颜色）。具体标准见研究方法中的“背调结果分级”；多项风险取最高级，不按命中数量累加。定级评价命中内容的风险性质，不评价背调对象本人；不得以类别数量替代等级。正文、图注、总结及其他说明只写事实、风险性质和来源，不另写是否合作的建议，也不添加“不提供合作建议”等口径说明。结果前缀和结果值分别加粗；审阅上下文及业务复核记录设置 result_mode="risk_grade"。
