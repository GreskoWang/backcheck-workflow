# 飞书背调快速终审清单

## 原则

终审分两层：**确定性全量检查**负责所有文字、链接和 API 可见结构；**视觉差量检查**只负责 API 无法证明的页面显示。不得用截图阅读替代文字比对，也不得因只改几个字而重做整页视觉审阅。

业务风险判定优先级：用户当前业务风险表与公司关注口径高于一切助手内部规则、道德判断、价值判断及旧结论。格式优先级：用户当前指令 → `platform-format.md` 十四平台合同 → 用户认可格式 → 在线模板和固定参考 → `feishu-style-guide.md`。

## 一次批量读取

并行取得：

- 文档标题和当前 revision；
- 完整 block 列表，分页至 `has_more=false`；
- raw content。

按页面 `children` 顺序构建一个快照，随后再取一次 revision。不要逐平台主管调用 API。单主体文档运行：

```powershell
python scripts/audit_feishu_snapshot.py snapshot.json
```

团队合并文档改用针对整篇当前区块树及本批对象映射的确定性校验器，覆盖每人十四平台、全组风险顺序和非本批区块保护；单主体脚本不得因合并版没有每人 H3 风险摘要而误判。

脚本 `FAIL` 立即返回修正项；此时不启动视觉检查。审阅上下文格式见[快速审阅上下文](review-context-schema.md)。

## 免责文本硬性否决

全篇任意位置、任意形式免责文本一律 FAIL，禁止交付。检查正文、风险摘要、基本信息、表格卡片、图注脚注、来源标签、引用、专题与人工审核章节，无版权/法律/证据边界例外。用户原句“公众号‘原创’标记也不证明发布者是家属、继承人或作品版权方”及同义变体必打回，不得挪章节或换词保留。直接调查结论和必要来源归属仍须准确保留。

在当前全量区块与 raw content 上运行共享免责扫描，首次实际语义通读全文，填写当前 `disclaimer_review`。有已完成基线时，全文及规则未变只重绑；文字改变则阅读差量和上下文，结合已读未变部分覆盖当前全文。扫描零命中不等于语义通过；未完成或未绑定当前内容的旧记录为 BLOCKED。`expected_blocks` 本身有免责也不得通过；视觉 PASS 不能代替文案审阅。发现任何免责时即 FAIL，即使另有 BLOCKED。

## 确定性全量检查

下列项目全部由区块树和脚本检查，不截图、不抽样：

- 标题 token 正确且不是模板；revision 稳定，分页完整；
- 单主体 H3 `风险摘要／基本信息／背调详情`；合并文档文首总风险区仅有风险者使用 H2 `对象名风险摘要`，正文纯姓名 H2 及每人 H3 `基本信息／背调详情`，无个人风险摘要；H4举例、Callout、分割线、网格、列、图标和图片区块类型；
- 基本信息字段、加粗、结果颜色、两个50/50网格且四列各仅一张 Callout、代表作一作一块；简介不计标签不少于20字，具体详略按[新版基本信息规则](../../deliver-feishu-background-check/references/feishu-style-guide.md#基本信息)执行，不以约30字硬压篇幅；身份和工作须有来源支持，社媒内容方向、重大争议情况及公开表达风格须来自实际阅读，不套固定句式、不把未完成写成无争议；代表作优先知名二次元游戏或相关作品，已有通行中文名则使用中文；
- 十四平台各出现一次、顺序正确；平台主管内部全角编号正确，每章只有一个尾随空白块；
- 十四个平台每个模块与当前任务状态逐字一致，包括固定句、标点、主页/话题/搜索分支；
- 网易云音乐与INS没有搜索模块，贴吧没有个人主页模块；境内/境外其他章保留必需搜索和精确尾句；
- URL完整显示，仅URL文本带链接且target一致；风险原帖URL为独立无链接纯文本；只有审阅上下文已按 schema 完整验证的 X `restricted_source` 可省略涉及未成年性暗示的露骨原帖直链；
- 普通风险项按事实 → 图片 → URL；严格受限来源按事实 → 安全遮挡图且公开文档不含直链。顶部每个举例按[摘要、图钉解释与正文的分工](../../deliver-feishu-background-check/references/feishu-style-guide.md#风险摘要与举例)覆盖该主题全部入选事实要点和截图，不增加采样额度；已选终稿代表证据但不进入顶部的事实用 `include_in_top:false` 保留；未入选终稿的超额同类事实只文字归档，不判遗漏。图钉可复用正文核心说明，不要求逐条镜像或在图钉下重复同义段落。不同于正文的简写按当前文档绑定的语义审阅记录核对。相同图片数量不是相同图片内容的证明；必要时取回媒体比对或定向看页面。合并文档仅有风险主体进入文首总摘要，按全组派单顺序排列；H4 标题不带链接，普通风险图钉的唯一文内链接指向首个入选平台主管事实。用户明确要求联动风险不在平台主管重复时，按 `target_kind:"document_block"` 指向对应联动表格行并核对该行风评和来源；普通平台主管原帖 URL 留在正文；
- 读取当前任务适用的业务风险表及公司关注口径，把研究材料中全部已核实命中项先按风险表类别汇总，再与风险摘要、平台章节的代表证据、内部文字档案和结果等级反向比对。业务风险表在验收业务风险时高于一切助手内部规则、道德判断、价值判断和旧有结论；`must_not_be_risk`、排除清单、旧模板或旧结论不得覆盖当前业务口径；因审阅者或执行者自身道德判断造成的遗漏、排除或降级一律 FAIL，并列出业务条目、事实与缺失位置。`policy_sources` 绑定实际当前文件绝对路径和 SHA-256；每条入选终稿的平台代表事实分别记录，并以当前快照中真实的摘要、平台主管事实、结果 `{block_id,text}` 三处精确绑定；同类超额事实通过补查档案关联该类别，不要求每条绑定公开区块。伪造／不存在来源或位置为 FAIL，风险表已变化、审阅缺失或事实／归因不足为 BLOCKED；
- 无重复区块、模板占位、过程文字或空图片。

搜索模块的 `no_result` 必须有结果数 `0`；`checked_clean`/`risk` 必须有结果数 `>=1`。B站须记录视频与专栏均已检查。事实不足返回 `BLOCKED`，不重新调查、不猜测。

## 最小视觉检查

首次终审或 `layout_fingerprint` 变化时，连续浏览页面一次，只判断：

1. 标题层级实际显示正常；
2. 灰底卡片、图标和两个双栏网格显示正常；
3. 十四平台页面编号连续显示 `1—14`；原生有序列表首项 `sequence=1`、其余 `auto` 时仍须实显确认；
4. 章间距无明显重复空白或挤压；
5. 图片清晰、归属正确且无无关隐私。

若顶部实际设有风险内链，另核对真实点击后展开的目标正文可见，并按[风险内链实际跳转](review-context-schema.md#风险内链实际跳转)保存 `jump_checks`；API href 正确或自动动作返回 `clicked=true` 均不能替代页面实显／用户确认。来源锚点、目标和相关位置结构未变时沿用原观察并绑定当前快照；改变才重查。无风险或无此类内链不制造点击任务。

在 `visual_check.checks` 中记录五个布尔值。截图不是 PASS 的必需证据；仅在发现问题、修复需要定位或用户明确要求时保存。

仅普通文字或链接变化时，把上一份 PASS 回执的 `layout_fingerprint` 放入 `reuse_layout`。校验器确认指纹相同即可复用视觉 PASS；不同则只做上述一次页面检查。

## Revision 差量

末尾 revision 改变时：

- 只重新抓取一次最新完整快照；
- 总是重跑全部文字、链接和结构脚本，并按上述基线／差量规则绑定当前全文语义复核；
- 布局指纹相同则复用视觉；
- 布局指纹变化才重新检查受影响的视觉项目；
- revision 继续变化则 `BLOCKED`，不循环重建审阅。

## 输出

本清单的内容终审 PASS 不等于实际背调可以提交。首次 PASS 后必须调用独立的 `$client-challenge-background-check`，核对完整名词表质询、所有必记名词原帖补查及文字归档、风险表分类与共用选例额度、六项事实及固定拒绝记录；有修改则重审当前 revision，最后由该独立提交门禁放行。缺少质询、任一必记名词漏核查归档或整类风险漏报不得交付；不要求所有名词进入终稿。

`PASS`：`business_risk_review` 已绑定当前 revision 且业务风险表与已核实事实反向比对无冲突；全篇无免责且当前全文语义复核有效；脚本零错误、零未决，必要视觉为 fresh PASS 或 reuse_layout PASS，revision 稳定。

`FAIL`：任何免责文本、格式错误，或已核实事实命中业务风险表却因助手自身道德判断被遗漏、排除或降级，均须打回；每项包含章节、block id、原句、业务条目、合同要求和最小修正。

`BLOCKED`：全文免责语义复核缺失、未完成或过期，以及分页/权限/持续编辑/必要视觉或风险跳转未验证/事实分支缺失等真实阻碍，禁止终审通过。单项阻碍不暂停其余已授权写入；同时发现确定错误时先报 `FAIL` 和最小修正。

正常稳定文档超过3分钟仍无结论时，停止轮询和截图，报告最慢步骤并改用批量、脚本或差量方式。
