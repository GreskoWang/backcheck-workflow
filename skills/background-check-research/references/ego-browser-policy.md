# 背调浏览器入口

调查、截图及飞书页面实显使用 Ego；公开搜索、获准公开 API、导出与本地材料可以配合使用。具体权限、空间恢复和止损规则以 [访问与工具规则](access-policy.md) 为准。飞书正文读写和终审使用 OpenAPI／MCP。

- 使用前读取当前 `ego-browser` Skill 并运行 `ego-browser skill`，按安装版本的接口操作。
- 优先复用本任务的 Agent 自有 TaskSpace。空间关闭或消失时，按访问规则新建并从原断点继续；用户接管、登录、验证码或安全拒绝不得当成空间丢失。
- 故障沿用既有恢复计数，累计三分钟无进展即保存断点，推进缓存、获准公开搜索/API、其他可执行平台及飞书 API 工作。Edge 和 web-access/CDP 不用于背调调查、截图或交付实显。
- 只读调查不授权发帖、关注、私信、付费或扩大账号权限；不提取认证材料，不用其他入口绕过明确拒绝。
- 离线脚本可以解包、去重、拼联系表和校验；下载或拼图生成不等于实际审阅。任务结束按 Ego 指南收尾，保护用户自有页面。
