# 调查方法

本文件补充普通背调中容易判断失误或拖慢进度的部分。目标是用最短路线发现值得记录的合作声誉风险。

## 通用排障方法

具体平台的等待特点、空结果判断和入口见[十四平台规程](platform-runbook.md)。以下办法跨平台复用；认证、权限和重试上限以[访问规则](access-policy.md)为准。

### 致命问题修复与沉淀

- 触发条件：故障阻断必要操作、导致证据丢失或足以使结论失真。每次发现都先检查已有方法，核对最小复现和直接原因，区分网站状态、控制器缺陷、能力不支持与真实权限限制。
- 在已有授权内先做最小、可撤回的修复或采用已验证替代；保护当前页面、已取得证据和交付内容。不能只解释原因、原样重复失败操作或等用户说“继续”。身份验证、扩大权限和无关系统修改不由这条规则授权。
- 修复须验证原失败场景确已恢复。代码变更按影响运行有针对性的回归检查，再实测原操作；修改文件、测试通过、HTTP成功或clicked=true都不能单独证明现场已修复。注明“代码已改／测试通过／运行实例已生效／现场通过”的实际状态。用户排除、接管、接受误差或替代通道成功只说明当次范围如何收束，不能删除历史故障或算原工具修好；下一批复发时先核运行版本和原场景验收，不从头索要用户已给的方法。
- 未得到有效进展时遵守原有止损预算，保存失败原因和断点，换路线并继续原任务。用户明确要求专项工具修复时，按该修复任务执行，不机械套用普通调查的短时试用上限；这不授权无限重试。
- 验证后立即沉淀：通用诊断与恢复放本文件，平台特例放platform-runbook.md对应平台，底层工具接口与实现放工具Skill。记录现象、原因、有效办法、验证日期、成功判据及失败后的下一步；未验证写待验证，失败写已知限制。检查并修正关联文件冲突，随后继续原调查，不把维护方法当成交付完成。

### 通用现象与处理

| 现象 | 处理办法 | 成功判据与不能推出的结论 |
| --- | --- | --- |
| 点击详情弹出新页后立即消失，响应只有clicked=true | 检查控制器弹窗规则。新版web-access点击响应的popupUrls保留同次受控点击产生、经脱敏的公开地址；在独立详情页打开并核对内容，原列表保持原处 | popupUrls为空仅表示短观察窗内未捕获可返回地址；filtered表示有地址被过滤，不等于帖子不存在。接口规则及验证见web-access的cdp-api.md；不得根据新页出现时间推断归属 |
| 页面只有框架、空白或占位 | 先核对网址、实际查询词、加载提示。若原页有可滚动内容，优先在同一滚动容器向上回滚少量距离，再向下回到原占位处触发续载；随后按平台已验证的时间等待。整页空白且无法滚动时直接等待；仍异常才在访问规则范围内最多刷新一次，刷新前保存断点 | 实际结果或平台明确认可的正常空结果状态出现才算有效；HTTP成功、ready=complete、空DOM都不能证明没有结果 |
| 滚动调用成功但内容不动 | 比较可见内容和实际滚动容器。内部面板看scroll返回的target/y/moved，不只看window.scrollY；重读当前视口或截图 | 文字、日期或画面确实改变才算推进。atEnd仅是已加载容器底部，moved=false不是历史终点 |
| 无限列表暂时不出下一批，或底部停在加载占位 | 保留原列表页和最后位置；优先在实际滚动容器向上回滚少量距离，再向下滚回原断点触发下一批，按平台时序等待。先执行有效恢复再判断，不能在atEnd或一次moved=false后先宣布失败。这一轮无新增的停滞累计最多3分钟，恢复最多一次，不另开同URL主页重跑；出现实际新内容表示该停滞已解除，随后从原处正常推进，不把3分钟当整页阅读限额 | 新正文、日期或图片实际出现才算恢复。正常渲染、有限恢复仍无更早内容时，记录本次可见范围，不声称绝对历史末尾；加载框架、错误、截断或未读占位记具体缺口。9/17用户已教“上滚再下滚”，9/22复验Facebook假终点，10/13王宇航据此由20项推进到69项；历史个案证据未收入复现包，现场状态需重新核验 |
| 文字读取被截断、截图与文本不一致 | 读取当前视口或具体结果容器，缩小查询；必要时以实际截图核对。不要反复增加整页读取量 | 已看见具体结果才能下结论；truncated=true或扫描达到上限表示工具没读完，不是页面没有内容 |
| 图片仍是占位，但文字已加载 | 优先在原列表页向上回滚少量距离，再下滚使该图重新进入视口，按平台时序等待；处在顶部无法上滚时，先下移少量再滚回占位处。仍未出图时在独立详情页打开已取得的原帖链接，保留列表页。跨帖重复作品复用已看缩略图 | 实际缩略图可见才计已看；按下文整屏缩略图规则筛查，不因未打开原图增加待办，也不把占位算已看。详情页仍不加载时只保留该项缺口 |
| 搜索结果混入同名、拆词或推荐内容 | 回读实际查询词及结果标签，使用原定额度内的一次消歧；检查署名、作品、职业与已知锚点 | 有转载或署名提及就是相关线索；核查无风险记“无问题”，不能写成“无相关内容”。范围已有效读完但结果无关，可按实际范围结束，不把无关结果永久列为工具故障 |
| 页面能读，某控制工具失败 | 分开判断正文读取、媒体加载、截图和点击能力；只隔离失败能力，复用已验证的允许通道，不在每个平台重复同一个失效控制器 | 成功替代只证明该操作已可完成，不能称原控制器被修复。截图失败不等于正文不能查；未尝试和仍可执行的步骤不列为受阻。拒绝和验证限制按访问规则处理 |
| 截图和读取能看见目标，点击却报不可见 | 核对点击与读取是否选择同一个可见元素；页面变化后重新定位，不长期复用旧index或文本。保留祖先隐藏、可编辑和遮挡检查；从原页取得公开链接，不要求用户代找本可自行定位的入口 | 必须核对目标页标题、身份与正文，clicked=true不算成功。只遮认证材料，保留公开帖子／主页标识；工具裁掉公开ID时修复工具或从原页取回，不猜补地址。2026-09-12抖音账号曾实测点击成功，不保证其他控件永久有效 |
| 接口返回成功但字段没改变 | 独立回读目标字段，比较真实前后状态；检查当前工具schema、官方资料和支持的接口，不猜字段连续写入 | 目标字段与页面效果确实改变才算成功；未知字段可能被忽略。结果不明先回读，不能重放写入制造重复块 |
| 已进入目标主页，但输出没有完整公开链接 | 先用当前浏览器通道读取网址；若该通道不提供网址，且该页确为当前任务此前访问过的公开页，可用web-access的find-url按准确标题、域名及任务日期查询少量本地历史，再打开所得公开URL核对账号 | 2026-09-12抖音实测成功：历史标题、实际主页账号与简介锚点一致后才回填。只查询任务相关公开页面，不读认证材料、不猜长ID，也不取消原工具脱敏 |

验证依据：2026-09-12合成主体021任务的B站完整续载、抖音延迟加载、贴吧与飞书内部滚动实测；[工具修复记录](../../../2026-09-11/合成主体021/process/工具修复说明.md)。这些是操作证据，不是今后每个平台必须复跑的检查清单。

新经验按主Skill的归档位置增量维护；同一根因合并，明确条件和成功判据。尚无稳定解法时记录已试方法、失败点和最小所需条件，继续独立工作，不把未经验证的尝试晋升为方法。

## 一遍式检查

浏览主页时保持同一列表页和从新到旧的单向顺序；仅风险核实、用户点名内容、必要展开项、重点视频或页面确实停滞可暂离列表，核完回原断点，不从顶部重扫。按页面顺序执行：

1. 确认当前内容属于哪个账号，以及是原创、回复、转发、引用还是点赞。
2. 阅读标题、正文、配文、展开说明和主体本人文字。
3. 看完当前帖的全部图片；视频列表先看标题和封面，重点视频再展开简介。
4. 按[原文阅读和名词提取](discovery-check.md)记录具体对象与上下文；名词表交给甲方，不前置全量背景查询。
5. 已识别且无疑点的正常内容继续；背景不明名称进入去重待查项，风险信号立即核实并保存最小证据。

批量工具先取得正文后仍须实际阅读和提取全部名词，保留原始来源。首尾摘要、命中数或缓存计数不代表阅读；无需名词查询子代理，执行[名词规程](discovery-check.md)。

Ego 卡住并按访问规则切换到 Edge 后，已接通的批量入口是 web-access `scripts/research-batch.mjs`，运行与版本条件见其 `references/research-batch.md`。复用本任务已租用的页，不另开第二套 CDP 连接。正文按实际字符数连续导出，长单帖可跨批，阅读者只确认读完的批次；不要按日期不等式切片漏掉边界当天，也不把短摘要当全文。公开图片先生成带来源的分页接触图，缺图保留格位，疑点再回原图。默认读者、采集者、飞书写者可处理不同域名或缓存；同一页面操作及同一注册域名的请求路线仍须互斥，不能用多页后台任务绕过本节故障隔离规则。查漏完成用通知／批次状态衔接，不循环询问。

### 关键词与语义信号升级核查

主页遍历同时做字面和语义识别，不以词表精确命中作为启动核查的前提。[名称识别](discovery-check.md)先于风险筛选；看似普通的名称也须识别其所指对象。出现下列任一信号时，把当前内容作为待核线索：

- 风险词、当地语变体、缩写、谐音、隐语、口号、组织名或事件名；
- 旗帜、徽记、手势、制服、地图、招募／募资页面、政治活动或其他能指向风险主题的画面；
- 没有直接关键词，但完整句意、历史典故、连续叙事或本人附言明显指向涉华主权、争议宗教组织、激进性别对立、违法涉毒、极端主义、仇恨歧视等主题；
- 评论区反复提到同一争议、事件或旧帖，并给出可追查的时间、原句、作品或链接线索。

对待核线索立即执行最小闭环：

1. 打开原帖或原内容，展开被折叠的正文、引用链和本人回复；记录当前遍历断点，核完后继续原顺序。
2. 核对账号归属，以及原创、转发附言、回复、点赞、第三方评论、角色台词、歌词或作品设定等真实归因。
3. 核对前后语境、发布时间和当地语言含义；结论依赖画面、音频或连续叙事时，查看足够清晰的原图、视频片段、字幕或相邻帖子。普通宗教活动、新闻转述、反串、引用批评和作品角色内容不能因关键词相同自动归为主体立场。
4. 若内容可能构成高风险或改变背调等级，使用独有短句、事件名、组织名和当地语变体执行该主题的一次主查询，必要时最多一次备用查询，核对原始出处、相关讨论及是否存在误传。找到足够语境即停止，不扩成全部词矩阵。
5. 在当前任务状态中把线索明确关闭为“已确认风险／已排除误报／尚待语言或事实复核”；没有完全相同字面词不构成排除理由，无法确认也不能静默跳过。

遍历中触发的风险闭环属于首轮调查，不占用常规调查后的画像补查问题。画像补查在甲方质询及最终成稿前执行，不以前置成品终审为条件。

## 账号处理决策

### 主页内的账号线索与角色判断

账号线索可以出现在任何已确认主页的简介、链接栏、关于页、置顶内容、图片文字或链接聚合页中，不限于 X。除完整 URL 和平台名称外，也要识别 emoji、平台颜色暗示、谐音、首字母、罗马字、账号格式和“其他平台见……”之类的自然表达。国内创作者可能用“📗”“红薯”等暗示小红书，用“🎵”暗示抖音、TikTok 或音乐平台；符号含义会随语境变化，只把它当作待核线索，结合相邻文字、handle 格式、实际落地链接和目标页内容判断，不能维护一张机械映射表后直接归属。

打开或搜索线索后，先给目标页判断角色：

- **本人个人或备用账号**：来源明确写成“我的／本人／其他平台／备用”等，或目标页的姓名、头像、作品、职业、自述和持续内容能够对应主体。纳入确认主页或疑似主页。
- **相关机构或项目**：事务所、经纪公司、组合、乐队、作品、活动、品牌、店铺、工作室等。可以用于继续发现本人账号，但机构发布内容不算主体本人发言。
- **其他自然人**：同事、朋友、家人、合作方、摄影师等。不得把对方主页和发言归给主体。
- **归属不明**：先作为疑似账号，快速看主页头部和少量内容；不足以判断时保留疑似，不为确认身份长时间停留。

“被确认主页链接”只证明存在公开关联，不自动证明账号归主体所有。链接聚合页的每个叶子链接都要分别判断角色，但只沿身份明确的一跳展开，避免沿事务所、同事或合作方继续递归。

### 确认主页

明确的本人归属标注，或公开互链、自述、作品、职业、头像、常用语言和活动信息能够直接对应主体时，视为确认主页，完整查看。单纯被确认主页链接不足以证明归属。优先读取每个确认主页的简介、链接栏、关于页、置顶内容和链接聚合页；由其明确标为本人所有、并持续以本人名义发布内容的社媒账号、个人博客或官网，是独立调查表面，也按确认主页处理。某一主页自身零命中不能覆盖它链接出去的其他本人主页。

### 同垂直领域的疑似主页

同名或相近 handle，且持续发布与主体相同垂直领域的内容时，直接纳入正常查看，不为身份验证阻塞调查。未自然获得更强锚点时，交付标签仍用“疑似主页”。用户明确提供的主页全部处理；除此之外，同一平台没有用户提供疑似页时，最多自动选一个与用户种子、handle、作品或头像最接近的同领域疑似主页，其余只快速查看主页头部并分类，不要求逐个扫到底。

### 内容很少

看完全部现有内容后记录“疑似主页 + 无问题”，不继续寻找生日、头像历史、注册信息或更多身份证明。

### 内容明显不相关

内容较多但职业、作品和主题明显不同，只需浏览到足以确认不一致。记录该账号主要发布什么及“与背调对象领域不一致”，随后停止。

### 疑似主页出现风险

检查一次最直接的身份线索，例如主页互链、自述或作品对应。仍不能确认时保留为“疑似主页风险线索”，不把内容写成主体本人行为。

## 主页内容

### 文字和图片

确认主页和纳入正常查看的疑似主页，其全部公开可见帖子从最新看到页面不再提供更早内容。查看正文、配文、引用附言、本人回复和每张配图。

图片先目视。视觉检查用于识别人物、动作、裸露、旗帜、徽记、历史政治符号和整体语境；OCR 只辅助读取图中文字，两者不能混称。只有密集小字、模糊文字、政治历史符号或其他风险信号需要 OCR 或放大；干净图片不保存。

批量图片先按[联系表批量看图必经流程](contact-sheet-review.md)分组、精确去重、编号并分页，默认每页36张，清晰纯画面可54张。实际逐格查看后，仅放大具体疑点、关键文字／符号不可辨或归属不清的编号。长图和密集文字按清晰度降低密度或分段，缺图保留编号。仅在线且无法取得可用批量材料时，才用作品列表、图文瀑布流或九宫格作为临时联系表；不能对已有批量图片退回逐图打开。已审同图复用图像判断，分别核对原帖文字与归属；生成联系表不等于看过图片。

同一平台每类通常选1—4例详细展开及截图，不凑数；其余材料继续阅读提词。甲方曾警惕原帖全部公开记录事实和链接，最终疑问列待确认，不能仅归档或以例数删除；见[呈现规则](risk-consolidation.md)。

### 视频

快速扫视频页公开显示的标题和封面。以下内容再打开简介并抽看：

- 置顶、热门和近期能代表账号形象的视频；
- 标题、封面、简介或评论出现风险信号的视频；
- 用户点名或与已知争议直接相关的视频。

重点视频只选少量、不重复的代表项，不按置顶、热门和近期分别凑数，也不随频道总量增加；风险项和用户点名项另行处理。只播放到足以确认语境。风险在音频或连续画面中时再扩大前后片段、字幕或转写。公开 API 能迅速批量取得标题、简介和公开封面时可一起扫读；封面很多时直接整屏筛查列表缩略图。大体量频道不要求逐个展开所有简介。不要下载整库、逐帧扫描所有视频或为普通视频制作时间线，也不能让视频处理阻塞文字帖子和其他平台。

封面可能是自定义宣传图，不一定是视频帧。只看封面时只能记录“账号发布的视频封面显示……”，不能写成“视频中出现……”或“字幕显示……”。封面本身含风险内容时，它可以作为账号公开展示内容核实；若结论依赖视频内真实动作、发言或字幕，必须回原视频页播放或读取相应片段。

### 评论

在近期代表内容、重点视频和疑似风险内容下查看热门或相关评论。关注反复出现的批评、抵制、投诉、圈内争议和对合作方的迁怒。

孤立低互动抱怨通常只作线索；多个独立用户反复讨论或已经形成明显舆情时，记录“存在何种公开讨论”。单一来源若传播量明显、来源可信或已经直接牵连合作方，也可以构成需要记录的舆情现象。第三方评论不能证明主体认同。

## 质询前的检索画像与补充二查

### 检索画像

完成十四平台常规调查后、甲方质询及最终成稿前，用一至数句写出当前任务内部检索画像，至少包含：

- 国家／地区、主要公开语言和受众市场；
- 职业及具体角色，例如声优、画师、作曲人、主播、公司创始人或品牌官方主体，而不是只写“创作者”；
- 已确认作品、合作对象、内容形态和主要公开平台；
- 与中国市场、游戏合作或本项目最相关的公开内容；
- 首次调查已经覆盖的主题和仍容易看漏的内容形态。

检索画像只服务于选择关键词，不判断主体属于什么政治、宗教、性别或人格类别。账号归属仍按“账号处理决策”核实，同名人物资料不得拼入检索画像。

画像形成后必须主动向自己提出一个具体的查漏问题，不等待用户再次追问。例如：“这个韩国音乐人有没有邪教／争议宗教组织、激进女权或性别对立相关公开内容？”问题可包含 1—3 个并列子题，但每个子题分别检索、分别记录是否出现；一个子题的零命中不能覆盖另一个子题。

地区和职业都提供候选词，实际选择取两者交集并结合首次调查的覆盖缺口。台湾、香港、韩国、欧美等对象的地区候选词，以及声优、画师、音乐人、主播、公司等职业候选词，见 `$env:BACKGROUND_CHECK_WORKSPACE\背调风险提示.md` 的“飞书成品后的检索画像与补充二查”和“国别与地区风险”。未列出的职业或主体类型由执行者根据职责、受众、作品、商业关系和已见内容自由建立检索画像与关键词。

### 选择补查方向

至少选择一个具体问题，通常包含一个子题；只有首次调查确实可能漏看多个重要主题时才增加，整个问题最多三个子题。依次比较：

1. 首次调查哪些内容形态、时间段或当地语言最容易漏看；
2. 与主体国别、职业、作品、受众和合作项目是否直接相关；
3. 主页、评论或名称搜索是否已经出现相邻词、同类主题或截断边界；
4. 哪一组关键词最能补足现有覆盖，而不是重复已经完成的搜索。

补查的目标是防止看漏，不是重新评价主体。若没有任何页面信号，就从国别与职业交集选一个首次调查未单独闭环的主题；若用户指定重点，直接检查该项。

这 1—3 个是常规调查后画像问题中的补查子题。补查中新出现的具体内容仍须回到原页核对，不把同一内容的近义词重复算成多个子题。

### 执行补充二查

每个选定方向视为一个风险主题：

1. 从风险提示库、主体原页面或当地讨论中为每个子题选少量有区分度的词，组合成一次主查询；外国主体优先使用当地常用语，必要时把中文或英文作为同一子题的一次备用查询。
2. 选择最能补足首次调查的入口，通常是百度、Google、当地主要搜索入口、主体内容最多的平台或首次调查存在可见边界的平台。人工查看实际生效查询的前三页或前 30 个唯一结果；平台不足该数量时以真实终点为准。
3. 主查询没有主体结果、同名污染严重或出现具体命中需要确认时，最多执行一次备用查询。补查必须使用比首轮宽搜更具体的关键词组合、身份消歧项、当地语言或不同平台入口，不得原样重放首次调查中的同一查询。命中后核对账号、原文、语境、时间、原创／回复／转发／点赞及第三方归因，排除平台界面词、同名人物、作品角色和无关转述。
4. 在当前任务状态中保留检索画像、具体问题、各子题的实际查询、查看范围和“出现对应内容／未出现对应内容／尚未完成”。不根据关键词给主体定性；若确认是成品遗漏，按对应平台规则补写事实和证据并重新审阅飞书。

只运行一个把政治、文化、宗教、性别等混在一起的宽泛查询，不算完成补查。零命中只能写“该子题的实际查询未出现对应内容”，不能覆盖其他子题，也不能推出主体历史上从未发布；至少完成一个具体问题后才能结束整项背调。

## 名称搜索与定向搜索

确认主体后先从确认主页、官网和可靠互链中整理最多 3 项实质不同的查询别名：当地文字主名、中文或英文常用名，以及当前 handle、明确旧艺名或旧 handle 中最有区分度的一项。不要生成大小写、空格、假名或罗马字的排列组合。百度优先使用中国用户实际使用的名称，境外平台和 Google 优先使用当地文字主名；账号发现时 handle 更有效，风评搜索时公众常用名通常更有效。

每个平台只执行一条名称搜索任务，选择最适合该平台的一项主查询，只看前三页或前 30 个唯一结果。首批完全没有主体或同名污染严重时，最多换一次别名或加入职业、组合、代表作消歧，结果总额度不重置。搜索可与主页批量采集并行：先看已给主页平台及境内／境外其他搜索的第一屏以获得风险线索，随后只补完剩余页数，不再重跑。

账号／用户搜索结果标签用于发现主页；综合、帖子、动态、视频、话题或讨论搜索结果标签用于发现风评。只落在用户、商品、作品、人物或曲目目录不算完成风评搜索，最多切换一次到综合或内容结果。同一查询在不同搜索结果标签间共享三页或 30 条总额度。这个额度只计算名称搜索结果，不计算主体主页时间线；确认主页和本轮纳入的疑似主页仍须把当前公开可见的文字帖子和配图全部看到页面终点。扫描每条搜索结果的标题、摘要、发布者、日期和可见缩略图；只打开主体相关、风险可疑或明显高互动的结果。

常规名称搜索后，结合国别、地区、职业、合作对象和主页内容，为整个对象合计选择 1—3 个最有信息量的定向组合。例：

- `对象名 + 台湾是国家／双十／政治`
- `对象名 + 靖国／旭日旗／军国主义`
- `对象名 + 反华／文化归属／争议宗教组织／激进女权`
- `对象名 + 台湾／西藏／反共／BLM／LGBTQ／已出现的政治议题`
- `对象名 + 已发现的具体争议、作品或合作方`

此处限制主动扩展的宽搜组合。解释名词优先原帖与通用知识；真正影响事实说明的不确定事项才针对性核实，单纯陌生不触发逐词查询任务。

这些只是组合方法，不是固定必搜清单。外国主体的重点方向优先至少使用一次当地常用语；当地语与中文／英文可作为同一主题的主查询和一次备用查询。具体词从当地页面、搜索建议或已有讨论中选择；出现明确事件词后直接替换宽泛风评词。社交时间线明显截断且平台支持作者范围筛选时，可把其中一条查询用于账号内检索；先用一条现存内容确认作者筛选有效，一次失败即停，零命中不支持历史结论。前三页没有主体相关结果或风险信号就结束，不通过增加几十个近义词证明“搜过”。外语关键词优先从原页面复制，用 URL 编码库或搜索框提交，不手写逐字百分号编码；加载后回读搜索框或结果标题，确认字符、假名和汉字与原词一致。

名称搜索、定向搜索和外部兜底共享轻量去重：同一 URL、规范化账号和争议主题只打开、归因和判断一次。出现具体风险线索时立即保留 URL、标题、摘要或帖子 ID；按风险主题只做一次主查询和最多一次备用查询，可用独有短句、原题、帖子 ID、原 URL 或当地事件名。找到可归因原文和足够语境即停；两次仍无可靠来源就记“未坐实”并停止。新的独立高风险事实才建立新主题，搜索结果换一种说法不算新主题。

个人站或博客的搜索器只有在至少能检出正文时才可用于正文候选筛选。首次依赖它时，从一篇已打开文章中取一个标题没有、正文独有的短语做一次正对照；能返回该文，只证明当前检索模式能命中这篇文章的正文。后续零命中只记为“当前检索模式未检出”，不证明全部历史正文均已入索引。只搜标题、查询未生效或检索范围不明时，改走归档、RSS、站点地图、公开抓取或外部索引。每个站点和检索模式校准一次即可，除非页面行为改变；正对照通过也不能把关键词搜索当成全量图文检查。

百度负责境内公开讨论，Google 负责境外公开讨论，也只看前三页。搜索摘要用于定位；真正记录风险时尽量打开原帖、原报道或完整讨论。

## 风险记录口径

先读取当前任务适用的业务风险表、公司关注口径与 `$env:BACKGROUND_CHECK_WORKSPACE\背调风险提示.md`。明确写为风险、必记、`均算风险`、`所有相关内容都算` 或同等含义的条目，在对象、行为与语境核实后直接按业务风险记录，不再要求额外通过普通玩家反感测试。只有这些口径未明确覆盖的候选内容，才继续判断它是否可能让普通玩家反感并牵连合作公司。

- **区分事实与业务结论。** 写主体公开表达了什么、转发了什么、图片呈现什么或社区在讨论什么；不要写“人品差”“违法”等未由可靠事实支持的结论。已核实的台独、反共或反华表达是明确的公司合作准入例外：事实归因和语义成立后，应写明触及不可妥协的政治红线并建议否决合作，这属于业务审核结论，不是对主体品德或法律责任的推断。
- **小纠纷要看规模和处理。** 单次迟发货、排期变化或普通服务失误，已说明并补救时通常不记录；反复、大面积、长期不处理、涉嫌欺骗或攻击消费者时再记录。
- **擦边看整体性暗示。** 普通 Cos 的露大腿、胸部、黑丝、贴身衣物不直接算擦边或色情。结合完整画面与语境，判断是否刻意营造性凝视，以及表情、色调、镜头角度、姿势、动作和配文是否有明确情色指向；单独露肤、低角度、脸红或汗滴不够。不能用“是否适合孩子看”替代这项判断；疑点只做必要的语境核验，不把一般角色服装与普通审美扩大成色情。
- **争议议题看中国语境。** 一般社会议题若存在稳定而明显的对立阵营，记录其公开立场及传播风险。台独、反共、反华不按普通争议议题处理，也不使用学术中立或言论自由话语弱化；核实成立即按公司绝对政治红线处理。
- **低争议要求很高。** 只有近似不同立场均可接受、几乎不会在中国互联网形成明显反对阵营的议题，才按低争议处理。
- **注意归因。** 原创、引用附言、本人回复、公开点赞、第三方原帖、第三方指控和媒体报道分别写清。

风险提示库是人工识别用的类别和例子。不要把整份词表交给搜索引擎遍历，也不要把自动关键词命中直接当成风险。这里限制的是未经核实的字面命中；已核实事实符合业务风险表明确规定的关联判定时，必须按该表记录，不能再用助手自己的价值或道德判断排除。

## 背调结果分级

用户于2026-09-12明确：成品“背调结果”是助手依据调查作出的判断，不是等待用户或上游提供的字段。按已核实风险的性质采用以下三级；多个风险并存时取其中最高级，一项满足条件即足够，不按帖子数量或风险例子数累积分级。

| 结果 | 用户规定的判断标准 |
| --- | --- |
| 建议谨慎评估 | 存在至少一项已核实的、在中国大陆高度敏感的主题风险，例如用户列举的辱华、辱华动漫、女拳、台独、反共等，不限于这些例子；以具体公开内容、原文语境和可确认的归因判断。其中台独、反共、反华一旦核实即为不可妥协的政治红线，必须明确建议否决合作，不得降格为一般争议或补充复核 |
| 建议评估 | 存在社会或道德争议，但其已核实性质尚未触及群众情感底线或国家法律法规；没有满足上一档的事实 |
| 低合作风险 | 仅有小事，或完成约定调查后未发现需记录问题 |

上述主题名称是查证线索，不是命中一个词就自动升级。核对本人发布、转发附言、第三方报道、作品归属及上下文；不能将他人的标签或指控当作事实，也不能从作品偏好、同名账号或关系人推断主体未公开披露的政治信仰等敏感个人属性。此归因边界只禁止外推私人属性：当前业务风险表若把已经核实的作品参与、制作、传播或公开表达列为业务风险，必须记录该参与事实和业务风险分类，不得以“不应推断私人属性”为由排除或降级。台独、反共、反华的本人表达一旦完成归因和语义核验，就必须执行最高档与否决合作结论，不再以“可能引发争议”等方式降级。涉及违法性质时仍核对可靠依据，不凭作品分级或标签认定违法。

调查尚未完成时可依据已核实风险填写当前判断，未完成平台和缺口仍明确保留，不能以暂未发现问题预填低合作风险；新增事实后重新核对等级。交付前核对分级、风险摘要及平台证据相互对应，交付步骤直接采用调查给出的等级。

## 截图与隐私

风险截图只证明两件事：内容是什么，以及为什么能归于该账号或该次互动。

- 保留账号名、必要头像或用户名，以及帖子文字、图片主体、转发／引用／点赞标记。
- 裁掉浏览器标签栏、地址栏、书签栏、扩展图标、系统任务栏、通知、聊天浮层、其他页面和无关推荐。
- 优先重新截取或裁切；必须遮挡时，只遮无关私人信息，不遮风险内容、时间、账号归属或互动关系。
- 上传飞书前再打开检查一次。整屏截图、能看到其他标签名的截图和包含无关私人内容的截图不得交付。

## 大账号与页面终点

- 优先使用公开 API、获授权导出或短时可用的采集器批量取得文字，再人工快速扫读。
- 静态博客先检查 RSS、站点地图、月份归档、归档分页和公开站内搜索。归档页能连续展示多篇正文和配图时，按归档页批量读取、去重并视觉扫图；不要为几千篇文章逐篇打开永久链接。站内全文搜索在完成一次正文正对照后，可用少量对象画像和已见信号相关的词簇优先找风险候选，但不能替代归档图文扫读，也不能固化为每名日本对象都跑同一组词。只有风险候选、截断正文或图片语境不清时再打开单篇原文。
- 数字文章 ID 连续的旧博客或论坛，在取得当前文章清单后顺手计算最小 ID 到最大 ID 的缺号。当前 sitemap、归档页与采集结果完全一致，只能证明当前公开范围抓全，不能证明没有历史删除帖。缺号少时先批量检查当前地址和公开索引残留，整站初筛最多 10 分钟；只有出现标题／正文残留，或相邻文章能确认旧平台迁移映射时，才对该缺号做一次网页存档检查。编号天然稀疏、缺口很多或没有线索时不穷举，不让历史恢复阻塞正常调查。
- 社交平台主页显示的累计帖子数与实际可见或可采集数不一致时，不把差额视为可枚举的“缺号”。累计数可能混合正文、回复、转发／引用、媒体、已删或受限内容，平台也可能限制时间线深度。按用户范围快速查看各实际可用内容入口；现成的日期搜索、公开 API 或获授权导出只有明显能补足可见范围时才短时使用，不为对齐总数开新工具试验。只留最早可见位置和停止原因；显示总数及逐帖唯一计数不作为普通背调必填项。没有具体风险信号时，到达本次可见边界就停止；有确切链接、争议或搜索残留时才定向追查对应内容。
- 按日期或页面分段，保留一个简单的最后日期或最后帖子位置，防止中断后重头开始。
- 无限滚动无新增时按上方“通用现象与处理”的同一轮 3 分钟规则判断：正常渲染且有限恢复仍无更早内容，就收束当前可见范围；错误、加载框架和未读占位保留缺口。已看范围不等于历史累计全部内容，不因缺少明确终点提示而无限等待或重开主页。
- 平台只展示有限历史时，记录实际可见范围并继续；“当前公开可见内容无问题”不能写成“历史累计内容全部无问题”，也不能让不可枚举的历史差额阻塞其他平台。
- 重复帖子、跨页重复和置顶回流要去重，但不制作逐条哈希或对账表。

## 删除内容、外语和不确定语义

已确认删除、封禁、关闭、隐私设置、限制查看或其他客观原因不可访问，优先按[访问结项规则](access-policy.md#客观不可访问项按无问题结项)记“无问题”并结项，不留待办，不等恢复。下述公开留存搜索是有具体线索时的有界核对，不是每条删除内容必须恢复的前置条件；已核实的留存风险不因原页删除而消失。

- 原帖删除、现站搜索残留或文章编号出现可疑缺口时，最多做一次网页存档或可信转贴搜索；迁移博客可先用相邻文章编号映射出旧地址。搜索结果有时会短暂保留已经删除的标题、正文或图片入口，发现风险信号后要立即保存原始 URL 并核对存档。能确认主体和原文时写“原页已删除，现有公开留存显示……”；不能确认就停止，不凭搜索摘要补正文。
- 只有风险结论确实依赖“图片是否本人拍摄、拍摄日期或设备归属”，且普通页面语境无法解决时，才查看公开图片的 EXIF，并与发帖日期、自述设备或其他独立线索交叉核对。EXIF 可缺失、被修改或随转载保留，只能作辅助佐证，不能单独证明本人到场或图片原创；已有第一人称正文和确认主页足以客观写成“该确认主页第一人称自述……”时，不再追加 EXIF，也不把这句话升级成本人到场或本人拍摄已被独立证实。
- 普通外语内容可快速机翻扫读。只有风险候选需要核对原文、上下文和当地语义。
- 双关、方言、政治暗语或历史典故无法确认时，写“疑似，需语言复核”，不要直接定性，也不要因此卡住其他内容。

## 工具选择

浏览器主路线固定为 Ego 优先、卡住后 Edge 后备；其他工具按当时速度选择：

1. 登录态 ego-browser 直接浏览；
2. Ego 卡住后，从断点切换到登录态 Edge／web-access；
3. 公开 API、获授权导出或已有批量采集器；
4. 网页搜索和公开原页；
5. 临时找到的开源工具。

评估新工具只看当前任务需要的最低事项：能否取得目标文本、是否会读取或导出凭证、是否调用私有接口、是否产生写操作。10 分钟没有取得有效样本就放弃。成功的操作经验按用户持续沉淀要求回填对应方法；新工具或依赖的安装、部署另按当前授权处理。

提交搜索、翻页或触发新内容批次后通常等待 5—10 秒；已经加载页面内的正常阅读和滚动不强制逐动作等待。同一站点一次只跑一条查询路线。官方 API 按其公开限速执行，首次出现 429 或验证页就停止并转做其他平台。

## 最小结论与可选暂存文件

飞书可用时，逐平台结论可从当前任务直接交付，不必为了流程重复写本地文件。飞书不可写、多人交接或任务可能中断时，使用 `调查结论.md` 暂存，建议结构如下：

```markdown
# 对象名
- 类别：
- 简介：
- 代表作：
- 飞书文档：

## 平台名
- 主页：
- 搜索：
- 账号状态：确认主页／疑似主页／无主页
- 结论：无问题

## 平台名
- 主页：
- 搜索：
- 账号状态：确认主页
- 风险：
  - 事实：
  - 归因：
  - 截图：
  - 原帖：
```

只写实际需要的字段。复用真实采集、逐条阅读、完整名词及来源，不新增逐词查询回执或质询逐轮哈希／重复台账。机器可复用已有采集指纹，不把普通质询变成取证审计。

## 故障隔离

- Ego 控制：一次正常尝试加一次状态读取后的恢复，累计 3 分钟仍无进展就保存断点并切换到 Edge；不新建 TaskSpace 重跑。用户接管、登录、验证码和权限提示按访问规则交给用户，不用 Edge 绕过。
- Edge 控制：切换后一次连接加一次恢复，累计 3 分钟后换其他允许路线。确认整条控制通道失效后不在每个平台重复重试，只有状态变化时再恢复一次。
- API 或脚本：同一组件和错误特征在全任务共享 10 分钟预算；换平台、执行者、参数或包装脚本不重置，取得明确新进展时才重新判断路线。
- 登录或验证码：保留一个待处理页，继续其他平台。
- 限流：停止该域名，先做其他工作；不在原地等待。经过平台提示时间或 10—30 分钟后最多再试一次。
- 飞书 API：一次重连仍失败时保存已写好的结论，继续研究；不得改用鼠标键盘编辑飞书正文。
- 子代理：普通调查由主代理推进；本阶段不创建名词查询代理。完成调查后按甲方技能创建一个无调查缓存的角色代理。每页仍只由一个执行者控制，同域名同一时刻一条请求路线。

所有故障只冻结对应平台、页面或工具，不得成为整项背调的总闸门。主号和必需范围优先于零星缺图、侧号和无证据历史考古；一个评论或截图恢复失败不阻其他可读内容。既有授权续期交给交付Skill，真实需要用户密码／验证码才挂起对应步骤；不要反复索要已给授权或把未尝试的工作记作受阻。

## 取证级审计

只有用户明确要求取证级穷尽审计时，才读取旧交接契约，建立研究包、逐项证据、哈希、查询矩阵、媒体时间线和严格校验。普通背调不要加载这些内容。
