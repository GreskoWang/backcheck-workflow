# 十四平台研究规程

本文件规定普通背调要检查的平台表面，并保存各平台特有的判断和操作办法。跨平台办法只保留在[通用排障方法](methods.md#通用排障方法)，平台章节不重复。以下特殊情况标明验证日期；日期代表经验来源，使用时仍以当前页面为准。所有平台遵循同一主线：

1. 处理确认主页和疑似主页；
2. 查看需要纳入主页的全部公开文字帖子和配图；
3. 快速扫视频页的标题和封面，查看重点视频的简介、内容及代表性评论；
4. 用主体名称或账号名执行一条平台原生搜索任务，在账号和内容搜索结果间合理切换，共计查看搜索结果的前三页或前 30 个唯一结果；这个上限只适用于名称搜索结果，不适用于主体主页，主体主页的公开文字帖子和配图仍按第 2 项全部看到当前可见终点；账号目录只用于发现主页，不能替代帖子、动态、视频、话题或讨论中的风评搜索；
5. 有画像或内容线索时，为整个对象合计追加 1—3 组定向搜索，优先放在百度、Google 或出现信号的平台；
6. 无风险记链接和“无问题”，有风险记事实、隐私裁切截图和原帖 URL。已确认删除、封禁、关闭、隐私页面、限制查看等客观不可访问项按[访问结项规则](access-policy.md#客观不可访问项按无问题结项)记“无问题”结项，不列待办，不阻止平台或整项任务完成。

本文件各平台章节和主 Skill 对“站内搜索一次”的重复说明指同一条任务，不叠加执行。站内搜索框恢复和因访问失败改走的 `site:` 公开索引属于同一路线的失败切换，不重新增加搜索结果的三页／30条额度；平台原生搜索仍需标明实际完成或局部受阻。全部搜索结果标签共享总额度，不能每个标签各扫三页；该额度与主体主页全量看帖无关。

平台章节固定顺序为：

`微博 → B站 → 抖音 → 小红书 → 知乎 → 网易云音乐 → 贴吧 → 豆瓣 → 境内其他内容 → X → Facebook → INS → 油管 → 境外其他网站`

调查可按可用性并行，只有飞书成品按该顺序排列。

## 1. 微博

- 看主页时间线中的原创、转发、引用附言、视频说明、图片和主体本人公开回复。
- 有超话或同名话题时，只查看与主体直接相关的近期或高互动内容和舆情，不遍历整个超话历史。
- 站内用主体名称或账号名搜索一次。

### 特殊情况与办法

- **搜索有署名转载却被写成无相关内容**：核对结果中的作者署名、作品和原帖；相关转载或提及经核查未见风险，应记“无问题”。第三方转载分别归因，不要求先找到本人微博才承认相关结果。2026-09-12用户截图反证“Y合成主体021Y无相关内容”，对应结论已更正；此类证据冲突按通用方法立即修正。

## 2. B站

- 看空间首页、动态、投稿视频、专栏、公开直播回放及实际存在的合集或课程。
- 动态和专栏按帖子处理；快速扫视频标题和封面，重点视频展开简介并播放。
- 站内查看与主体有关的用户、视频、动态或专栏搜索结果。

### 特殊情况与办法

- **旧动态续载暂缓（2026-09-12实测）**：保持一个专用动态列表页，初次可等约20秒；每步约650px，到已加载底部后每隔约5秒观察。连续约6次没有新内容，向上1—2步后向下重入；短观察批次结束不是失败判决。无明确错误时保留原页，允许暂缓累计约2分钟再检查；取得新帖子后从原处继续。在既有访问止损上限内仍无进展时保存最后日期和页面状态，切换其他可做工作，不从顶部重翻。
- **真实终点**：优先看“你已经到达世界的尽头”等页面提示，结合最后日期和再次滚动状态。实测同一页从最新内容越过2025年5月、2024年12月及11月28日停点，最终到2022-07-29并出现该提示；11月28日曾等待超过一分钟才恢复，不能用两次空加载认定结束。[复验记录与终点截图](../../../2026-09-11/合成主体021/process/工具修复说明.md)。
- **查看图片后后退导致旧动态丢失**：列表页不承担图片或原帖详情导航；疑点在另一个任务详情页处理并及时关闭。优先从已加载列表保留原帖公开链接，避免列表缓存淘汰后被迫重翻。
- **同屏多个日期时的精确点击（2026-09-17复验）**：先以视口查询 `.bili-dyn-time` 确认目标日期，增量滚动至它成为第一条可见日期，再对该选择器执行一次 `clickAt`；响应中的 `element.text` 必须等于目标日期，且 `popupUrls` 给出独立原帖地址，随后在详情页核作者、完整时间与正文。稻乙緹 2026-04-01 动态据此取得并核实 https://t.bilibili.com/1000000000000000123；若点击返回的日期不符或地址未捕获，只按上述止损和原页状态恢复一次，不依据位置猜帖子ID。
- **动态图片占位的可用替代（2026-09-12复验）**：有真实原帖链接时，在独立详情页打开并等待约20秒；工房头像定制原帖实测一屏显示3张缩略图。可直接筛查，不必逐张打开原图；这证明该原帖路线有效，不保证所有隐藏图集项都能恢复。详情页仍占位的按通用方法保留具体缺口。
- **作品很多但列表缩略图清晰**：已取得批量图片先按[联系表流程](contact-sheet-review.md)逐格审阅；仅在线且无法取得可用批量材料时，从空间“投稿→图文”的实际入口整屏扫作品瀑布流；已验证路由形态为 `https://space.bilibili.com/<UID>/upload/opus`。它适合本人作品和已定位原帖，不覆盖转发文字与未展示的图集项；缩略图与同类风险最多4例按通用方法执行。
- **采集分页为空**：曾出现首屏有数据、后续offset返回空列表，而网页仍可继续显示旧帖。只记该采集路线不可靠，转回已验证的页面续载；不将空items、重复offset当作账号历史终点，不重复调试同一失败接口。
- **空间视频页的按钮分页（2026-09-17实测）**：`/video` 页底部若实际显示 `1 2 下一页` 三个相邻按钮，可滚到页底后用受控点击选中第二个页码；本次简洁选择器 `button + button + button` 返回 `element.text=2`，随后页面转到 `/upload/video` 并显示不同的旧视频标题，才确认翻页成功。选择器是当前页面结构的现场办法，不保证其他账号通用；点击返回的按钮文字或新标题不符时停止猜选择器，保留分页缺口，改用其他允许路线。

## 3. 抖音

- 看主页作品、图文和实际可见的动态或转发。
- 图文看完配图；视频查看标题、封面和说明，重点内容再播放。
- 站内用主体名称或账号名搜索一次。

### 特殊情况与办法

- **搜索只显示框架（2026-09-12实测）**：固定等待7秒曾误判失败；保持同一页等待约30秒后，实际查询词、综合／视频／用户标签及结果均出现。以后先给足这一加载窗口，再按通用方法判断，不固定7秒退出，也不把框架当作零结果。
- **同名用户与作品一起返回**：用公开抖音号、头像和多幅已知作品对应关系判断账号；搜到用户不等于该主页内容已查完。工具脱敏了主页地址时不猜补长ID、不去掉脱敏规则；只通过可用的页面公开入口或已取得的真实链接继续。没有入口时保留具体缺口。
- **可见账号点击报不可见／新页被关闭（2026-09-12已现场修复）**：对应通用点击定位办法。修复后的broker会跳过隐藏副本，并在同一受控页跟随普通新页链接；实测从搜索结果中的账号名进入本人主页，主页显示31个作品，简介的Pixiv账号与已确认锚点一致。首次仍等待约30秒，点击后核对真实主页再继续，不把地址脱敏当成无法阅读主页。

## 4. 小红书

- 看主页笔记、图文、视频及主体本人公开回复。
- 图集按[联系表流程](contact-sheet-review.md)逐格审阅；长图、密集小字或符号看不清时放大／分段，OCR只作辅助。仅在线且无法取得可用批量材料时，整屏查看可见缩略图并保留未展示项。
- 收藏、被标记内容和第三方互动不能当成主体发布。
- 站内用主体名称或账号名搜索一次。

### 特殊情况与办法

- **详情直达显示 300011／404，但主页卡片可正常打开（2026-10-14 实测）**：确认本人主页后，优先从主页网格点击真实笔记卡片进入详情，并保留列表页及当前位置。单独拼接或打开笔记详情 URL 若出现 `300011`／`404`，只说明该直达路线失败，不能据此判定详情不可访问；正常卡片点击可能携带当前页面的 `xsec`、来源或会话上下文。卡片成功打开后，撤销此前基于直达失败形成的阻断推断，以实显详情核对正文、所选重点笔记的全部图片、视频及可见评论／主体回复，再返回原列表断点继续。不得点赞、关注或评论。只有同一主页内正常卡片点击在有限恢复后也失败，或实显不可绕过的登录／验证／权限阻挡时，才记录对应访问边界。

## 5. 知乎

- 看回答、文章、想法、提问、视频和主体本人公开回复中实际存在的部分。
- 区分主体回答、他人问题、作品条目和第三方评论。
- 站内用主体名称或账号名搜索一次。

### 特殊情况与办法

- **AI摘要提及主体，但标识与锚点冲突（2026-09-12实测）**：以实际主页和原帖核对，摘要不能替代身份依据。该任务曾出现摘要中的Pixiv编号与已确认编号不同，未据此合并账号。近名用户主页实显无动态且回答／文章／视频为0时，可按低内容疑似主页规则完成，不继续为确认身份反复搜索。

## 6. 网易云音乐

- 个人主页、音乐人页同时存在时都看；动态、节目、视频和公开说明属于发言范围。
- 曲目和专辑目录只用于确认身份与作品，不自动视为主体立场。
- 站内用主体名称或账号名搜索一次，并看相关内容下的代表性互动。

## 7. 贴吧

- 有个人主页时看其公开发帖和本人回复。
- 有主体相关主题吧时，查看与主体直接相关的近期或高互动主题，不遍历整个吧。
- 站内用主体名称或账号名搜索一次；个人发言与吧内第三方讨论分开归因。

### 特殊情况与办法

- **搜索拆词及近名主题吧**：核对实际查询和结果，按原定一次消歧及总额度处理，不能把近名主题吧归给主体。普通HTTP入口若返回百度安全验证，停止该路线；已可用的登录态页面可继续正常阅读，不绕过验证、不把HTTP失败写成无内容。

## 8. 豆瓣

- 看确认用户主页的广播、评论、讨论及其他公开发言。
- 豆瓣人物页、作品条目和用户主页分开；人物或作品目录只支持身份和作品信息。
- 站内用主体名称或账号名搜索一次。

### 特殊情况与办法

- **正常空结果区（2026-09-12用户明确确认）**：页面正常显示、查询词正确而结果区为空，即按无相关内容处理；不要求出现“0条结果”或专门的无结果文字。将其与整页空白、加载框架、登录墙和错误页区分；这是豆瓣的明确判断，不自动推广为所有平台空DOM皆无结果。

## 9. 境内其他内容

- 用百度搜索主体主名称，查看前三页。
- 对前三页中新发现的境内平台主页，按“确认／同领域疑似／低内容疑似／领域不一致”规则处理。
- 根据画像或已出现线索，在全对象 1—3 组的建议范围内追加定向查询。搜索摘要只用于发现，风险尽量回到原始页面。
- TapTap、NGA、米画师、LOFTER、官网、新闻、论坛等按实际发现列为具名子平台，不为不存在的平台造账号。

### 森空岛

- **域名响应不稳定、页面迟迟不出内容**：原页已有可滚动内容或加载占位时，优先小幅上滚、再下滚回占位处触发续载（2026-09-18用户复验）；整页空白且无法滚动时正常等待。仍未加载再按平台时序等待，并在访问上限内最多刷新一次，刷新前保存断点。2026-09-12已有实际完整读取至终点的结果，不能继续沿用“连接受阻”这一旧标签。恢复后依新增帖子和终点判断，不能只看请求成功。
- **多图预览与“+N”（2026-09-24 实测）**：主页预览不能作为隐藏余图已核的结论；取得可确认的原帖 `article?id=...` 直链后，进入详情核作者、日期和 `1/N` 总数，再逐张查看纳入范围的公开图片，并将本人正文／回复与第三方评论分别归因。合成主体007置顶帖由用户提供 `article?id=3555659` 后实核 14/14 张，见 `新任务过程目录/历史验证证据未保留`。详情不可得时保留未见的访问边界，不猜测或枚举连续文章 ID。

### 米画师

- **调查范围（2026-09-12用户明确要求）**：只检查目标个人主页，不进行平台名称搜索或全站风评搜索。定位到目标主页后，查看其公开简介、作品、橱窗和评价；不再为平台搜索入口增加待办。主页尚未定位时，只沿已确认账号提供的昵称或链接寻找该主页。
- **官网正常却没有画师名称检索入口（2026-09-12复验）**：未登录状态下官网、作品页、橱窗 `/stalls`、`/stalls/list` 及画师目录 `/artists?page=390` 可显示内容；分类和档期筛选不等于画师名称搜索。不要继续循环首页或遍历数百页画师目录。
- **入口选择**：优先使用确认主页给出的完整分享链接；只有准确昵称时使用上面的昵称路径。进入目标主页后即结束账号定位，不继续寻找站内搜索、App搜索或其他同名账号。两种定位均失败才保留该主页的具体入口缺口，不能写成无主页。[官网](https://www.mihuashi.com/)。
- **主页标签与评价续载（2026-09-12实测）**：先查询`.el-tabs__item`的可见文字，确认作品／橱窗／评价的实际顺序后点击对应项。评价初开曾只显示框架，稍后出现首批10条；滚至该列表底部后补出余下2条，与主页12条计数对应。以实际新增内容和数量判断，不能将初始空框架写成无评价，也不跳出目标主页去搜索评价者。

## 10. X

- 看 Posts、Replies、Reposts／Quotes 和 Media 中实际存在的公开内容。
- 原创、回复、纯转发和引用附言分别归因；公开点赞只有页面确实显示时才记录。
- 站内用主体名称或账号名搜索一次。记录当前可见最早帖日期，供飞书“背调时间”字段使用，不制作终点证明。
- X 搜索首批结果若不含查询主体、只显示默认实时流或无关内容，按访问规则恢复一次后立即改用公开索引兜底，不反复调试搜索页，也不把无关结果算作已检查。
- **已知 X 原帖网页 403，但官方公开嵌入可读（2026-10-07 实测）**：已有明确原帖 URL 时，可短时使用 `https://publish.twitter.com/oembed?url=编码后的原帖URL` 核对公开作者、账号、日期和嵌入文字，不读取凭证或私有接口。作者、原帖链接和日期对应且关键文字实际返回才算文本核验成功；长帖可能截断，附件原图、视频及评论没有因此完成，仍回原页或明确标注的公开转载补核。404 只表示嵌入接口本次未提供内容，不单独证明删除；一次失败即保留原帖缺口并换路线，不改用非公开接口。证据：`新任务过程目录/历史验证证据未保留`、`cassie-commission-oembed.json`、`cassie-clarification-oembed.json`、`yamato-wuwa-oembed.json`；同任务 2023 年原帖嵌入 404。

## 11. Facebook

- 看主页或 Page 的 Posts、Reels、Videos、Photos 中实际存在的公开内容。
- Page 自有内容、访客帖和第三方评论分开。
- 站内用主体名称或账号名搜索一次。

## 12. INS

- 看 Posts、Reels，以及调查时仍公开可见的 Highlights／Stories；按用户既有授权直接只读浏览，留下浏览记录可以接受。不得点赞、评论、关注、私信、切号或绕过隐私设置。
- Tagged 内容是第三方内容；只有主体另有明确互动才记录该互动。
- 站内用主体名称或账号名搜索一次。

### 特殊情况与办法

- **主页网格链接带用户名时公开嵌入页返回 404（2026-09-15 实测）**：Instagram 主页 DOM 可能把帖子或短视频链接写成 `/用户名/p/<shortcode>/`、`/用户名/reel/<shortcode>/`；页面本身可以打开，但把该路径直接追加 `/embed/captioned/` 会返回 404。批量读取公开配文前，保留 shortcode 并规范化为 `/p/<shortcode>/embed/captioned/` 或 `/reel/<shortcode>/embed/captioned/`。规范化后 Alex Keem 主页当前可见 81 条主网格内容及 2 条仅在 Reels 页出现的内容均成功读取；用户名前缀路径的 404 只说明嵌入地址格式不对，不能记为内容删除或不可访问。
