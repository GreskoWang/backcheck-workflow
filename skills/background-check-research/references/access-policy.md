# 访问与工具规则

本文件只规定浏览器、登录、公开 API、临时工具和故障止损。调查范围看 [十四平台规程](platform-runbook.md)，判断方法看 [调查方法](methods.md)。

## Edge 优先

- 用户发起背调，即授权执行者在任务范围内自主打开、选择和操作带持久用户配置及登录态的 Microsoft Edge，进行只读浏览、搜索、滚动、翻页和截图；无需逐页请求许可。
- 优先按 `$web-access` 使用本地 CDP broker 连接持久 Edge，避免依赖容易脱落的扩展调试句柄。同一页只由一个控制器操作。
- 多个执行者可以同时持有不同的 Edge 任务页并推进不同平台；同一页面仍只允许一个 owner，同一域名的 5—10 秒节奏、验证码和限流熔断由所有执行者共享。全部执行者合计最多主动占用 5 个任务页；broker 对可归属页面执行这一准入上限。
- 不把 Codex 内置／in-app 浏览器作为普通平台调查通道。它不共享 Edge 登录态，也不能代替登录页面、视觉判断或风险原页截图。
- 公开网页搜索、公开 API、获授权导出和本地脚本可以与 Edge 配合；登录态页面、图片判断和风险原页核实仍优先回到 Edge。
- 用户已允许背调时直接只读浏览公开可见的 Instagram 精选集／Stories，即使留下浏览记录也无需为此暂停或逐条确认；这不授权点赞、评论、关注、私信、切换账号或绕过非公开限制。

## 页面与并发

专项修复例外：用户明确要求修复正在阻断任务的控制器缺陷时，按web-access SKILL.md“脚本弹窗地址与专项修复”执行必要的受控broker重载；这不适用于普通工具更新，也不允许重启Edge或丢弃原任务页面。其他情况下继续遵守下述连接保持规则。

- 同一任务会话的全部执行者合计最多由 broker 主动放行 5 个可归属 Edge 任务页额度，包括已管理页面、lease、待创建页面和可能弹窗的点击预留；达到 5 个后禁止第 6 个 `/new`、无关 `/acquire` 及可能弹窗的点击。CDP 明确给出受控 `openerId` 时，派生页原子承接点击预留并由 broker 自动关闭。`Page.windowOpen` 没有 target id，只标记同一次 broker 点击的短时事件乱序保护额度，保护窗结束自动释放；没有明确 `openerId` 时，不得根据相同 URL 或出现时间推断、读取或关闭 target。关闭未确认的明确派生页或认证创建标记页继续占额度，并暂停新的页面占用和可能弹窗的点击，直到 broker 重试成功或 Edge 确认页面消失。网站或浏览器自主产生的多弹窗、延迟弹窗、无 `openerId` 弹窗及断线期间弹窗可能使实际物理页数瞬时超过 5，发现后立即停止新开页并收口。本任务通常保持 1—3 页。既有用户页完成后立即 release；broker 自建任务页必须 finalize 关闭后才释放额度。只统计可归属任务控制页，不读取、关闭或计入用户无关页签。
- 第一次远程调试连接获准后，正式交付完成前保持可见 Edge 进程和同一 CDP broker 持续运行。不得在任务中途为了加载代码、诊断或清理内存而关闭或重启；所有执行者复用该连接，普通页面操作不再请求授权。已去除创建标记的页面管理关系保存在当前 broker 进程内，外部重启后必须重新盘点，不能假定跨进程恢复。若进程被外部关闭，用户不在时只挂起浏览器路线并继续其他工作，不循环拉起授权。
- 同一注册域名同一时刻只由一个执行者运行浏览器搜索、翻页、API 或脚本请求，其他执行者处理不同域名或已导出的内容。提交搜索、翻页或触发一个新的内容批次后通常等待 5—10 秒；已经加载页面内的正常阅读和滚动不强制逐动作等待。
- 站内搜索页打开后，先确认查询词回读正确、结果属于综合／帖子／动态／视频／话题等内容表面，再按[通用排障方法](methods.md#通用排障方法)及平台特殊情况判断加载和结果状态。正常空结果是否需要提示文字由平台规程或用户明确判断决定，不统一要求必须显示“0条”。只出现账号、商品、作品目录时最多切换一次综合或内容标签；整页空白、加载中、登录墙、错误页及未生效查询的默认实时流不算零命中。查询已生效且规定范围实际读完但全为无关结果时，可按该有效范围收束，不机械判为工具失效。需要恢复搜索时，最多在同一页用可用搜索框恢复一次，仍失败就改用外部搜索引擎的 `site:平台域名 主体名` 或其他公开索引，并把站内路线记为局部受阻。恢复和外部兜底属于同一条名称搜索的失败切换，不重复增加三页额度；外部索引零命中只能写“当前公开索引未检出”。
- 日文及其他外语查询优先从原页面复制，并交给 URL 编码库或站内搜索框编码；不要手工拼逐字百分号编码。提交后回读搜索框、结果标题或页面显示的查询词，确认原字符没有错字、同形字替换或乱码。
- 只有在把个人站或博客搜索器用于正文筛选时，才做一次正文独有短语的正对照，确认当前检索模式至少能返回这篇文章的正文命中；这不证明全部历史正文均已入索引。每个站点和检索模式只校准一次，页面行为异常时再重做。零命中只能记为当前检索模式未检出，不能替代主页和归档内容检查。
- 重型单页应用采用小步读取和滚动。页面变化后重新定位元素，不长期复用旧句柄，不请求整页 HTML、全 DOM 或全量可访问性树。

## 登录与验证

遇到登录墙、验证码或二次验证：

1. 在 Edge 中保留一个对应任务页和原目标 URL；
2. 只挂起该平台，其他平台、工具和飞书回填继续；
3. 需要账号、密码、验证码或二次验证时，请用户本人在该页完成；
4. 用户不在时不轮询、不反复刷新，等用户回来后最多恢复一次。

不得读取、记录、截图、导出或重放密码、Cookie、token、CSRF、Bearer、浏览器配置或其他认证材料。不得绕过验证码、登录墙、年龄限制或付费权限。

## 公开 API、导出与脚本

- 公开 API、官方接口、获授权导出和已有采集器可用于账号发现、批量取文字、分页、去重和翻译。浏览器已登录不等于获得 API 权限。同一组件和同一错误特征在整个任务中共享 10 分钟试错预算，不因更换平台、执行者、参数或包装脚本重新计时；3 分钟和 10 分钟都是止损上限，不要求等满。
- 不调用私有网页接口，不提取页面凭证，不使用账号池、代理轮换或验证绕过。
- 官方 API 遵守公开限速；出现 429 或明确等待时间时立即停止并遵守提示。
- 可临时搜索 GitHub 或互联网寻找公开工具。先检查它是否读取凭证、调用私有接口或产生写操作，再用一个小样本试跑。10 分钟内不能取得有效结果就停止调试。
- 临时工具成功后可以完成当前任务；说明实际解决的问题和收益。用户已授权持续沉淀操作经验，按主Skill规定直接回填通用方法或平台章节；安装、引入新依赖和工具部署仍核对实际授权，方法更新不自动授权扩大工具权限。

## 连接和限流止损

- Edge 控制、CDP 附着或单个页面动作：正常尝试一次，恢复一次；累计 3 分钟没有进展就冻结该页面并换路线。已经确认整条 Edge 控制通道失效后，不在每个平台分别重复这套恢复；只有用户重连、Edge 重启、冷却结束或状态确实变化时再试一次。
- 出现 `Debugger unattached`、CDP 超时、target 丢失或控制内核重置时，不连续重复相同长超时调用。页面能显示与调试连接可用是两回事。
- 工具因无法可靠识别浏览器URL而拒绝控制时，不禁用识别或绕过其安全检查。遵守该通道停止要求；后续允许的工作可使用已正常验证网址和页面归属的Edge broker。将状态记录为“替代通道可用，原控制器未修复”，不要求所有备用控制器修复后才继续调查。2026-09-12已验证broker可完成B站续载、抖音页面读取和贴吧内部滚动；这不证明Windows Computer Use或扩展CUA已经恢复。
- 出现验证码、验证页、403、412、429 或明确限流时，停止该站点的当前访问路线，先做其他平台；经过平台提示时间或 10—30 分钟后最多再试一次。这里停止的是访问路线，不是整个背调任务。
- 空白页或加载框架本身不能证明限流、域名受阻或无相关内容。先读取页面状态；原页可滚动时优先按[通用排障方法](methods.md#通用排障方法)小幅上滚再下滚触发续载，无法滚动时正常等待。在上述 3 分钟恢复上限内按平台时序等待，仍异常最多刷新一次；用户已说明域名加载不稳定时也按此处理。仍无有效页面时记录“页面未加载完成”，换路线并继续其他待办，不反复创建页面或把每次恢复重新计时。
- 同一组件和错误特征的 API 或脚本在全任务累计 10 分钟仍无有效样本时，改用 Edge、网页搜索或其他现成方法，不在其他平台或执行者处重新开始计时。
- 创建、导航、滚动等结果不明时，先读取当前页面状态再决定是否重试，避免制造重复页签或跳过内容。

任何技术故障只影响对应页面、平台或工具，不得阻塞其他平台和已完成结果的飞书回填。

## 截图隐私

- 截图只包含账号归属和风险内容所需区域：账号名或头像、帖子文字或图片主体、必要的转发／引用／点赞标记。第三方评论截图默认遮掉与事实无关的头像、昵称和用户编号，只保留理解来源与讨论所必需的信息。
- 不得露出浏览器标签栏、地址栏、书签栏、扩展图标、系统任务栏、通知、其他页签、聊天窗口或无关推荐内容。
- 优先重新截取或裁切；必要遮挡只覆盖无关私人信息，不能遮住风险事实、账号归属、时间或互动关系。
- 上传或交付前再次打开截图检查。发现无关私人信息时先修正，不得直接使用整屏截图。
- 优先直接截取主体区域。因工具限制产生的未裁切整屏图只能暂存在任务 `process` 目录；裁切成品确认可用后删除该临时整屏图。
