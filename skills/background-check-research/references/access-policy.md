# 访问与工具规则

本文件只规定浏览器、登录、公开 API、临时工具和故障止损。调查范围看 [十四平台规程](platform-runbook.md)，判断方法看 [调查方法](methods.md)。

## 客观不可访问项按无问题结项

用户于 2026-11-11 明确规定：已确认帖子被删除、账号被封禁／注销／关闭、网站关闭、页面为隐私页面、贴主限制查看、媒体失效，或因其他已核实的客观原因不可访问，**该不可访问项按“无问题”结项**。这属于已完成的核查结果，不是待办、覆盖缺口或必须恢复的材料；不得因此中止任务、阻止平台完成、终审、交付或 Goal 完成，也不得等待贴主恢复、解除限制或网站重新上线。

- 明确的平台提示或已有可靠访问记录足以确认时立即结项，不要求反复尝试所有工具。原因尚不明确时按本文件的有界恢复检查；已确认客观不可访问后不再重试，不绕过隐私、登录、验证码或安全拒绝。
- 在既有任务状态保留原 URL、实际提示／访问依据和客观原因，记录 `status:"complete"`、`conclusion:"无问题"`、`access_outcome:"objective_unavailable"`；从活动待办中移出。没有正文就不虚构已读正文、媒体或身份。这里的“无问题”是用户指定的该项业务结论，不等于声称已看过不可见内容。
- 此规则只结清不可访问的项目。已有公开留存中核实的风险继续保留；同一平台仍可访问但尚未执行的工作继续完成。偶发超时、空白加载、工具失效或尚未尝试，本身不能证明内容已被删除或设为隐私，也不自动得到该结论。
- 全量遍历的完成范围是实际可公开取得的内容加已确认客观不可访问的终态项，不包含恢复所有历史删除内容。不得把终态项重新列为 `pending`、`open_items`、`incomplete` 或 `blocked`。后续出现实质新证据时再按新证据复核。
- 本节同样适用于整条帖子、引用上文、媒体、账号、主页和网站。对已确认的客观不可访问项，本节优先于流程中关于“材料缺失／未读／未完成”的一般规则；不得在交付、终审或甲方质询时将其重新转成待办。

## Ego 优先，Edge 卡住时后备

- 用户发起背调，即授权执行者在任务范围内创建或恢复一个 Agent 自有的 ego-browser（ego lite）TaskSpace，并用默认浏览器配置进行只读浏览、搜索、滚动、翻页和截图；无需为创建该 TaskSpace 或逐页操作再次请求许可。每项背调只创建一个 TaskSpace，后续轮次按 `spaceId` 恢复，不以新建空间处理卡页。开始前运行 `ego-browser skill` 并遵守当前安装版本指南；不检查或选择其他 Profile，除非用户明确指定。
- Ego 是普通背调、特殊背调和专项调查的默认页面入口。同一页只由一个控制器操作；优先复用同一页按顺序导航，确有需要才在同一 TaskSpace 增加页面。页面是否可读以实际标题、正文、画面或控件实显为准，命令成功、空间存在和导航返回不能单独证明完成。
- Ego 页面、续载或控制动作卡住时，先读取当前页面状态并做一次有界恢复；累计 3 分钟仍没有可验收进展，保存目标 URL、最后位置、已读范围和恢复次数，再把该页面或平台切换到 `$web-access` 的持久登录态 Microsoft Edge，从断点继续，不在 Ego 新建 TaskSpace 或同网址页面重跑。切换成功只证明后备路线可用，不代表 Ego 故障已修复。
- 用户已接管 TaskSpace、Ego 报告空间 inactive／unassigned、浏览器权限提示、登录、验证码或二次验证时，按 Ego 指南停止自动操作并交给用户处理；这类明确的人机交接不得通过 Edge 绕开。用户确认完成后才恢复同一空间。不得读取、复制或转移 Cookie、token 或其他认证材料来同步两种浏览器。
- 切换到 Edge 时，按 `$web-access` 使用本地 CDP broker，不依赖扩展调试句柄。普通背调及其配套工具修复不调用 Windows Computer Use／CUA 检查或操作 Edge，包括查看连接弹窗、确认窗口状态和截图，也不把它作为交付或 Goal 的前置条件。获准 shell 下的 `web-access/scripts/cdp-session.ps1` 是 Edge 后备入口；工具清单缺少 Computer Use、Browser 或 Node REPL 时仍应检查该入口。正常切换先检查既有 broker，`connected` 且 `approvalRequired=false` 时，在本任务原有、归属明确且持有有效租约的页面用 `/info` 和小范围正文验证，通过后从断点继续。脚本存在或连接成功不能单独证明页面可读。
- Edge broker 明确要求授权时，简短说明当前连接状态；只有确认存在待处理的 Edge 授权提示，才请用户点击“允许”，不调用 CUA 查看或代点。等待期间继续已读缓存、分析和获准的飞书工作稿，不反复重载制造提示。超时不证明弹窗存在，也不证明用户未授权。
- 多个执行者可以持有不同任务页并推进不同平台；同一页面仍只允许一个 owner，同一域名的 5—10 秒节奏、验证码和限流熔断由所有执行者及 Ego／Edge 路线共享。全部执行者合计通常保持 1—3 个主动任务页，不超过 5；切换浏览器不重置页面、请求或重试额度。
- 不把 Codex 内置／in-app 浏览器作为普通平台调查通道。它不共享 Ego 或 Edge 登录态，也不能代替登录页面、视觉判断或风险原页截图。
- 公开网页搜索、公开 API、获授权导出和本地脚本可以与 Ego／Edge 配合；登录态页面、图片判断和风险原页核实优先在 Ego 完成，Ego 卡住后回到 Edge 后备路线。
- 用户已允许背调时直接只读浏览公开可见的 Instagram 精选集／Stories，即使留下浏览记录也无需为此暂停或逐条确认；这不授权点赞、评论、关注、私信、切换账号或绕过非公开限制。

## 页面与并发

专项修复例外：用户明确要求修复正在阻断任务的控制器缺陷时，按当前 ego-browser Skill 或 web-access SKILL.md“脚本弹窗地址与专项修复”处理；web-access 的受控 broker 重载不适用于普通工具更新，也不允许重启 Edge 或丢弃原任务页面。其他情况下继续遵守下述连接保持规则。

- 一个背调 TaskSpace 通常保持 1—3 个 Ego 任务页，不超过当前运行时报告的页面预算；优先复用页面，不为每个平台、图片或重试新建页面。完成任务后按 Ego 指南 `finish({ keep: [] })`；只有用户明确要求保留结果页时才保留指定页面。用户自有或来源不明的页不关闭、不接管，除非用户明确批准。
- 同一任务会话的全部执行者合计最多由 broker 主动放行 5 个可归属 Edge 任务页额度，包括已管理页面、lease、待创建页面和可能弹窗的点击预留；达到 5 个后禁止第 6 个 `/new`、无关 `/acquire` 及可能弹窗的点击。CDP 明确给出受控 `openerId` 时，派生页原子承接点击预留并由 broker 自动关闭。`Page.windowOpen` 没有 target id，只标记同一次 broker 点击的短时事件乱序保护额度，保护窗结束自动释放；没有明确 `openerId` 时，不得根据相同 URL 或出现时间推断、读取或关闭 target。关闭未确认的明确派生页或认证创建标记页继续占额度，并暂停新的页面占用和可能弹窗的点击，直到 broker 重试成功或 Edge 确认页面消失。网站或浏览器自主产生的多弹窗、延迟弹窗、无 `openerId` 弹窗及断线期间弹窗可能使实际物理页数瞬时超过 5，发现后立即停止新开页并收口。本任务通常保持 1—3 页。既有用户页完成后立即 release；broker 自建任务页必须 finalize 关闭后才释放额度。只统计可归属任务控制页，不读取、关闭或计入用户无关页签。
- 第一次远程调试连接获准后，正式交付完成前保持可见 Edge 进程和同一 CDP broker 持续运行。不得在任务中途为了加载代码、诊断或清理内存而关闭或重启；所有执行者复用该连接，普通页面操作不再请求授权。已去除创建标记的页面管理关系保存在当前 broker 进程内，外部重启后必须重新盘点，不能假定跨进程恢复。若进程被外部关闭，用户不在时只挂起浏览器路线并继续其他工作，不循环拉起授权。
- 同一注册域名同一时刻只由一个执行者运行浏览器搜索、翻页、API 或脚本请求，其他执行者处理不同域名或已导出的内容。提交搜索、翻页或触发一个新的内容批次后通常等待 5—10 秒；已经加载页面内的正常阅读和滚动不强制逐动作等待。
- 站内搜索页打开后，先确认查询词回读正确、结果属于综合／帖子／动态／视频／话题等内容表面，再按[通用排障方法](methods.md#通用排障方法)及平台特殊情况判断加载和结果状态。正常空结果是否需要提示文字由平台规程或用户明确判断决定，不统一要求必须显示“0条”。只出现账号、商品、作品目录时最多切换一次综合或内容标签；整页空白、加载中、登录墙、错误页及未生效查询的默认实时流不算零命中。查询已生效且规定范围实际读完但全为无关结果时，可按该有效范围收束，不机械判为工具失效。需要恢复搜索时，最多在同一页用可用搜索框恢复一次，仍失败就改用外部搜索引擎的 `site:平台域名 主体名` 或其他公开索引，并把站内路线记为局部受阻。恢复和外部兜底属于同一条名称搜索的失败切换，不重复增加三页额度；外部索引零命中只能写“当前公开索引未检出”。
- 日文及其他外语查询优先从原页面复制，并交给 URL 编码库或站内搜索框编码；不要手工拼逐字百分号编码。提交后回读搜索框、结果标题或页面显示的查询词，确认原字符没有错字、同形字替换或乱码。
- 只有在把个人站或博客搜索器用于正文筛选时，才做一次正文独有短语的正对照，确认当前检索模式至少能返回这篇文章的正文命中；这不证明全部历史正文均已入索引。每个站点和检索模式只校准一次，页面行为异常时再重做。零命中只能记为当前检索模式未检出，不能替代主页和归档内容检查。
- 重型单页应用采用小步读取和滚动。页面变化后重新定位元素，不长期复用旧句柄，不请求整页 HTML、全 DOM 或全量可访问性树。

## 登录与验证

遇到登录墙、验证码或二次验证：

1. 在当前任务浏览器中保留一个对应任务页和原目标 URL；Ego 路线按当前指南 `handOff()` 给用户，Edge 后备路线保留原页；
2. 只挂起该平台，其他平台、工具和飞书回填继续；
3. 需要账号、密码、验证码或二次验证时，请用户本人在该页完成；
4. 用户不在时不轮询、不反复刷新，等用户回来后最多恢复一次。

不得读取、记录、截图、导出或重放密码、Cookie、token、CSRF、Bearer、浏览器配置或其他认证材料。不得绕过验证码、登录墙、年龄限制或付费权限。

## 公开 API、导出与脚本

- 公开 API、官方接口、获授权导出和已有采集器可用于账号发现、批量取文字、分页、去重和翻译。浏览器已登录不等于获得 API 权限。同一组件和同一错误特征在整个任务中共享 10 分钟试错预算，不因更换平台、执行者、参数或包装脚本重新计时；3 分钟和 10 分钟都是止损上限，不要求等满。
- 不调用私有网页接口，不提取页面凭证，不使用账号池、代理轮换或验证绕过。
- 官方 API 遵守公开限速；出现 429 或明确等待时间时立即停止并遵守提示。
- 可临时搜索 GitHub 或互联网寻找公开工具。先检查它是否读取凭证、调用私有接口或产生写操作，再用一个小样本试跑。10 分钟内不能取得有效结果就停止调试。
- 临时工具成功后可以完成当前任务；说明实际解决的问题和收益。用户已授权持续沉淀操作经验，按主Skill规定直接回填通用方法或平台章节；安装、引入新依赖和工具部署仍核对实际授权，方法更新不自动授权扩大工具权限。

## 连接和限流止损

- Ego 控制或单个页面动作：正常尝试一次，读取当前状态后恢复一次；累计 3 分钟没有进展就保存断点并切换该页面或平台到 web-access/Edge。用户接管、权限提示、登录或验证不属于可绕过的卡页，按上文交给用户。
- Edge 控制、CDP 附着或单个页面动作：切换后正常尝试一次，恢复一次；累计 3 分钟没有进展就冻结该页面并换其他允许路线。已经确认整条 Edge 控制通道失效后，不在每个平台分别重复这套恢复；只有用户重连、Edge 重启、冷却结束或状态确实变化时再试一次。
- 出现 `Debugger unattached`、CDP 超时、target 丢失或控制内核重置时，不连续重复相同长超时调用。页面能显示与调试连接可用是两回事。
- 工具因无法可靠识别浏览器 URL 而明确拒绝控制时，遵守停止范围，不禁用识别、不换入口重试被拒绝动作，不以新回合视为拒绝已解除。继续工作仅限不涉及该拒绝的独立获准任务。正常情况下，按既定 CDP 路线核验网址与页面归属即可，不要求所有备用控制器先修复。历史 CDP 成功不证明原生 Computer Use 已修复，也不授权绕过安全检查。
- 将局部故障及剩余材料保留在已有当前结论/待办中，不另建重复状态。只有全部剩余的获准工作均无法推进，且同一真实阻碍已连续至少三个 Goal 回合时，整个 Goal 才按工具规则 blocked；单个平台或控制器的三次失败不能直接代替这项判断。
- 出现验证码、验证页、403、412、429 或明确限流时，停止该站点的当前访问路线，先做其他平台；经过平台提示时间或 10—30 分钟后最多再试一次。这里停止的是访问路线，不是整个背调任务。
- 空白页或加载框架本身不能证明限流、域名受阻或无相关内容。先读取页面状态；原页可滚动时优先按[通用排障方法](methods.md#通用排障方法)小幅上滚再下滚触发续载，无法滚动时正常等待。在上述 3 分钟恢复上限内按平台时序等待，仍异常最多刷新一次；用户已说明域名加载不稳定时也按此处理。仍无有效页面时记录“页面未加载完成”，换路线并继续其他待办，不反复创建页面或把每次恢复重新计时。
- 同一组件和错误特征的 API 或脚本在全任务累计 10 分钟仍无有效样本时，改用 Edge、网页搜索或其他现成方法，不在其他平台或执行者处重新开始计时。
- 创建、导航、滚动等结果不明时，先读取当前页面状态再决定是否重试，避免制造重复页签或跳过内容。

任何技术故障只影响对应页面、平台或工具，不得阻塞其他平台和已完成结果的飞书回填。

## 截图隐私

- 截图只包含账号归属和风险内容所需区域：账号名或头像、帖子文字或图片主体、必要的转发／引用／点赞标记。第三方评论截图默认遮掉与事实无关的头像、昵称和用户编号，只保留理解来源与讨论所必需的信息。
- 不得露出浏览器标签栏、地址栏、书签栏、扩展图标、系统任务栏、通知、其他页签、聊天窗口或无关推荐内容。
- 优先重新截取或裁切；必要遮挡只覆盖无关私人信息，不能遮住风险事实、账号归属、时间或互动关系。
- 上传或交付前再次打开截图检查。发现无关私人信息时先修正，不得直接使用整屏截图。
- 优先直接截取主体区域。因工具限制产生的未裁切整屏图只能暂存在任务 `process` 目录；裁切成品确认可用后删除该临时整屏图。

## 权限边界

背调授权只包括公开信息的只读调查和用户要求的飞书交付。不得代替用户发帖、评论、点赞、关注、私信或修改任何平台账号。
