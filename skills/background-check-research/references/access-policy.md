# 访问与工具规则

本文件是浏览器、登录、公开 API、临时工具和故障止损的统一规则；[Ego 入口](ego-browser-policy.md)只负责导航，不另设限制。调查范围看 [十四平台规程](platform-runbook.md)，判断方法看 [调查方法](methods.md)。

## 客观不可访问项按无问题结项

用户于 2026-11-11 明确规定：已确认帖子被删除、账号被封禁／注销／关闭、网站关闭、页面为隐私页面、贴主限制查看、媒体失效，或因其他已核实的客观原因不可访问，**该不可访问项按“无问题”结项**。这属于已完成的核查结果，不是待办、覆盖缺口或必须恢复的材料；不得因此中止任务、阻止平台完成、终审、交付或 Goal 完成，也不得等待贴主恢复、解除限制或网站重新上线。

- 明确的平台提示或已有可靠访问记录足以确认时立即结项，不要求反复尝试所有工具。原因尚不明确时按本文件的有界恢复检查；已确认客观不可访问后不再重试，不绕过隐私、登录、验证码或安全拒绝。
- 在既有任务状态保留原 URL、实际提示／访问依据和客观原因，记录 `status:"complete"`、`conclusion:"无问题"`、`access_outcome:"objective_unavailable"`；从活动待办中移出。没有正文就不虚构已读正文、媒体或身份。这里的“无问题”是用户指定的该项业务结论，不等于声称已看过不可见内容。
- 此规则只结清不可访问的项目。已有公开留存中核实的风险继续保留；同一平台仍可访问但尚未执行的工作继续完成。偶发超时、空白加载、工具失效或尚未尝试，本身不能证明内容已被删除或设为隐私，也不自动得到该结论。
- 全量遍历的完成范围是实际可公开取得的内容加已确认客观不可访问的终态项，不包含恢复所有历史删除内容。不得把终态项重新列为 `pending`、`open_items`、`incomplete` 或 `blocked`。后续出现实质新证据时再按新证据复核。
- 本节同样适用于整条帖子、引用上文、媒体、账号、主页和网站。对已确认的客观不可访问项，本节优先于流程中关于“材料缺失／未读／未完成”的一般规则；不得在交付、终审或甲方质询时将其重新转成待办。

## Ego 浏览器与空间恢复

- 背调默认使用 ego-browser。用户已授权创建 Agent 自有 TaskSpace，开始前运行 `ego-browser skill`；不检查或切换其他 Profile。
- 空间可用时按 spaceId 复用；**TaskSpace 被关闭或消失时，无需询问用户，直接新建本任务的 Agent 自有空间**，记录旧新 spaceId，按已保存 URL、位置和阅读范围恢复。新建空间不重置同域名重试、限流或调查进度，也不从首页重读已核实材料。
- **Edge 及 web-access/CDP 不再作为背调备用工具**，包括调查、截图和交付实显。Ego 页面卡住时读取状态并有界恢复一次；累计 3 分钟没有进展即保存断点，继续已读缓存、公开搜索／获准公开 API、其他可执行平台和飞书 API 工作。
- 空间关闭或消失与用户仍在接管、明确安全拒绝、登录和验证码不同。仍属于用户或已交还用户的空间不得接管；新建空间不能用于绕过登录、验证、权限提示或安全拒绝。明确用户专属步骤按原权限边界处理。
- 页面可读须以实际标题、正文、图像或控件验证；空间创建成功或导航成功本身不是已读证明。同页只由一个控制器操作，通常保持 1—3 个任务页，遵守运行时预算。
- 允许范围内的公开网页搜索、公开 API、导出和本地材料可配合 Ego 使用；不得借其他来源绕过已明确拒绝的访问。Instagram 公开 Stories 的只读浏览沿用任务授权，不授权点赞、评论或私信。

## 页面与并发

任务完成按 Ego 指南 `finish({keep:[]})` 收尾；用户要求保留的页按指示处理。用户自有或来源不明页不关闭、不接管。

- 同一注册域名同一时刻只由一个执行者运行浏览器搜索、翻页、API 或脚本请求，其他执行者处理不同域名或已导出的内容。提交搜索、翻页或触发一个新的内容批次后通常等待 5—10 秒；已经加载页面内的正常阅读和滚动不强制逐动作等待。
- 站内搜索页打开后，先确认查询词回读正确、结果属于综合／帖子／动态／视频／话题等内容表面，再按[通用排障方法](methods.md#通用排障方法)及平台特殊情况判断加载和结果状态。正常空结果是否需要提示文字由平台规程或用户明确判断决定，不统一要求必须显示“0条”。只出现账号、商品、作品目录时最多切换一次综合或内容标签；整页空白、加载中、登录墙、错误页及未生效查询的默认实时流不算零命中。查询已生效且规定范围实际读完但全为无关结果时，可按该有效范围收束，不机械判为工具失效。需要恢复搜索时，最多在同一页用可用搜索框恢复一次，仍失败就改用外部搜索引擎的 `site:平台域名 主体名` 或其他公开索引，并把站内路线记为局部受阻。恢复和外部兜底属于同一条名称搜索的失败切换，不重复增加三页额度；外部索引零命中只能写“当前公开索引未检出”。
- 日文及其他外语查询优先从原页面复制，并交给 URL 编码库或站内搜索框编码；不要手工拼逐字百分号编码。提交后回读搜索框、结果标题或页面显示的查询词，确认原字符没有错字、同形字替换或乱码。
- 只有在把个人站或博客搜索器用于正文筛选时，才做一次正文独有短语的正对照，确认当前检索模式至少能返回这篇文章的正文命中；这不证明全部历史正文均已入索引。每个站点和检索模式只校准一次，页面行为异常时再重做。零命中只能记为当前检索模式未检出，不能替代主页和归档内容检查。
- 重型单页应用采用小步读取和滚动。页面变化后重新定位元素，不长期复用旧句柄，不请求整页 HTML、全 DOM 或全量可访问性树。

## 登录与验证

遇到登录墙、验证码或二次验证：

1. 在当前任务浏览器中保留一个对应任务页和原目标 URL；按 Ego 当前指南 `handOff()` 给用户；
2. 只挂起该平台，其他平台、工具和飞书回填继续；
3. 需要账号、密码、验证码或二次验证时，请用户本人在该页完成；
4. 用户不在时不轮询、不反复刷新，等用户回来后最多恢复一次。

不得读取、记录、截图、导出或重放密码、Cookie、token、CSRF、Bearer、浏览器配置或其他认证材料。不得绕过验证码、登录墙、年龄限制或付费权限。

## 公开 API、导出与脚本

- 公开 API、官方接口、获授权导出和已有采集器可用于账号发现、批量取文字、分页、去重和翻译。浏览器已登录不等于获得 API 权限。同一组件和同一错误特征在整个任务中共享 10 分钟试错预算，不因更换平台、执行者、参数或包装脚本重新计时；3 分钟和 10 分钟都是止损上限，不要求等满。
- 不调用私有网页接口，不提取页面凭证，不使用账号池、代理轮换或验证绕过。
- 官方 API 遵守公开限速；出现 429 或明确等待时间时立即停止并遵守提示。
- 可临时搜索 GitHub 或互联网寻找公开工具。先检查它是否读取凭证、调用私有接口或产生写操作，再用一个小样本试跑。10 分钟内不能取得有效结果就停止调试。
- 临时工具成功后可以完成当前任务；说明实际解决的问题和收益。用户已授权持续沉淀操作经验，按主Skill规定直接回填通用方法或平台章节；安装、引入新依赖和工具部署仍核对实际授权，方法更新不自动授权扩大工具权限。

## 连接和限流止损

- Ego 控制或单个页面动作正常尝试一次，读取状态后恢复一次；累计 3 分钟没有进展保存断点并推进其他获准工作。空间已关闭或消失可直接新建任务空间；登录、验证和明确安全拒绝按上文边界处理。
- 控制超时或页面丢失时，不连续重复相同长超时调用；先核对空间与页面状态，按上文恢复。
- 工具明确安全／权限拒绝时按其实际范围停止，不禁用识别、不换入口或空间重试被拒绝动作；继续不涉及该拒绝的独立工作。
- 将局部故障及剩余材料保留在已有当前结论/待办中，不另建重复状态。只有全部剩余的获准工作均无法推进，且同一真实阻碍已连续至少三个 Goal 回合时，整个 Goal 才按工具规则 blocked；单个平台或控制器的三次失败不能直接代替这项判断。
- 出现验证码、验证页、403、412、429 或明确限流时，停止该站点的当前访问路线，先做其他平台；经过平台提示时间或 10—30 分钟后最多再试一次。这里停止的是访问路线，不是整个背调任务。
- 空白页或加载框架本身不能证明限流、域名受阻或无相关内容。先读取页面状态；原页可滚动时优先按[通用排障方法](methods.md#通用排障方法)小幅上滚再下滚触发续载，无法滚动时正常等待。在上述 3 分钟恢复上限内按平台时序等待，仍异常最多刷新一次；用户已说明域名加载不稳定时也按此处理。仍无有效页面时记录“页面未加载完成”，换路线并继续其他待办，不反复创建页面或把每次恢复重新计时。
- 同一组件和错误特征的 API 或脚本在全任务累计 10 分钟仍无有效样本时，改用获准公开搜索或已有材料，不在其他平台或执行者处重新开始计时。
- 创建、导航、滚动等结果不明时，先读取当前页面状态再决定是否重试，避免制造重复页签或跳过内容。

任何技术故障只影响对应页面、平台或工具，不得阻塞其他平台和已完成结果的飞书回填。

## 截图隐私

- 截图只包含账号归属和风险内容所需区域：账号名或头像、帖子文字或图片主体、必要的转发／引用／点赞标记。第三方评论截图默认遮掉与事实无关的头像、昵称和用户编号，只保留理解来源与讨论所必需的信息。
- 不得露出浏览器标签栏、地址栏、书签栏、扩展图标、系统任务栏、通知、其他页签、聊天窗口或无关推荐内容。
- 优先重新截取或裁切；必要遮挡只覆盖无关私人信息，不能遮住风险事实、账号归属、时间或互动关系。
- 上传或交付前再次打开截图检查。发现无关私人信息时先修正，不得直接使用整屏截图。
- 优先直接截取主体区域。因工具限制产生的未裁切整屏图只能暂存在任务 `process` 目录；裁切成品确认可用后删除该临时整屏图。

## 权限边界

背调授权只包括公开信息的只读调查和用户要求的飞书交付。不得代替用户发帖、评论、点赞、关注、私信或修改任何平台账号。

甲方任一轮曾警惕的原帖适用最新收录规则：后续不可访问本身不撤销已闭环事实，按标准格式记录；未闭环疑问和访问状态只留内部，用户明确审定的删除按最新指令执行；不虚构未见内容，也不把未知写成已坐实。
