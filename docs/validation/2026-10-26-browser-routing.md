# 浏览器路由及隔离修复验收

普通背调、特殊背调及专项调查以 PowerShell CDP 客户端为默认浏览器入口，不先调用原生 Computer Use 做健康检查。缺少 Computer Use、Browser 或 Node REPL 工具不等于 CDP 客户端不存在。预检现在明确报告入口，同时明确页面读取尚未验证。

局部路线故障保留为原待办中的缺口，继续独立获准工作。只有所有真实剩余工作均不可推进且满足连续三轮阻塞规则时才将整个 Goal 标为 blocked。明确安全/权限拒绝仍须遵守，不能借换工具、换回合或换会话重试被拒绝动作。

broker 已修复 release、租约过期及迟到清理错误解除隔离的问题。截图被 CDP 超时、外层超时或客户端取消时保留隔离；截图限定视口，并报告无正文的耗时与错误阶段。保持原有权限校验和 CDP 方法白名单。

9 项隔离测试、7 项截图生命周期测试，以及 broker 安全/租约/队列、完整集成、HTTP 边界、会话清理和截图文件校验均通过。普通请求的 PNG/JPEG 保存、失败不覆盖旧文件均受现有校验约束。

在独立公共测试页完成真实验收：PNG 923ms，执行中取消截图后 release/acquire 仍拒绝普通读取，一次显式 recover 后同页 JPEG 1103ms。实际查看图片，测试页确认关闭。维护期间 Edge 进程与原任务页面保留，未修改任务断点或恢复计数。第一次维护握手超时，用户明确要求再次握手后连接成功，没有追加重载。

本次发布不声称修复 Windows 原生网址识别，也不声称已经定位并消除历史 Edge 截图卡顿。原失败页已不存在，未从新页或普通测试页成功推断历史页恢复。原生控制器不是普通背调继续推进的必需依赖，必要来源核验和真实范围缺口仍必须保留。
