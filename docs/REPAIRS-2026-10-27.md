# 2026-10-27 修复发布与验证边界

这次发布整合已部署并验证的修复，以及桥接器所需的配套模块和回归用例。原有风险库、模板、调查方法、写作及交付格式保持原样。仓库仅供团队私下协作，群 ID、负责人和团队规则按维护者要求保留；本机目录、凭据、浏览器状态、研究缓存、任务断点和原始运行日志不随源码发布。

## 修复内容

- CDP 元数据读取超时不再直接断开所有人的连接，先在同一已验证连接做一次有界健康检查，检查失败仍退役失效连接。不会在后台循环重连或制造新的授权提示。
- DOM 请求中止、超时和动作结果未知时保留页面隔离，不自动重放。显式恢复必须通过页面返回结构、状态和租约身份验证，失败不能解除隔离。
- PowerShell 会话客户端明确区分普通失败和动作结果未知，清理路径保留页面和原断点。普通会话自测预算改为 10 秒，覆盖进程启动、请求和清理；正式客户端默认 25 秒，连接握手为 30 秒，均有上限。
- 采集器使用修订后的可见正文和视口配方，继续保留去重、正文截断及未展开标记。采集成功、页底、空白和灰占位都不能被当成完成阅读。
- 紧凑阅读缓存更新时对齐来源和媒体签名，保留已有阅读确认与最小断点，修复新增材料、媒体变化和不完整任务的协调。无问题材料不恢复逐帖留档，也不新增重复导出或状态副本。
- 接单回执绑定准确的来源群、请求和发送身份，结果不确定时先受控回读，不凭相似群名或 ID 后缀重发。交付审阅恢复复用同请求的原研究和成品，不重新启动研究或重放交付。
- 诊断工具检查实际配置的 Python 解释器；团队合并审阅保留全文和实显证据要求。依赖补齐 `openpyxl`，表格渲染从系统字体目录或 `BACKCHECK_FONTS_DIR` 读取字体，不写死本机盘符。

## 复现回归

本次发布的 51 组回归及必要复测通过，见 [发布回归摘要](../reports/repair-release-2026-10-27.json)。摘要保留早期失败及其修正依据，未将预跑失败写成通过。

在独立安装目录完成依赖安装，加载仓库的 `recovery-session-env.ps1` 后执行：

```powershell
python -X utf8 scripts/check_portability.py
python -X utf8 scripts/run-regression.py --group all
python -X utf8 scripts/package.py
```

`run-regression.py` 使用合成配置、隔离临时目录和 loopback 假服务，覆盖浏览器、桥接器、Python 阅读/审阅、UAT 以及 `tests/repair` 专项用例。它不启动正式监听，不使用真实浏览器，不读取业务断点。可用 `--group repair` 单独执行本轮专项回归。原始结果保存在被 Git 忽略的 `reports/local/`，发布用摘要只保留相对文件名和检查结果。

测试中的代理环境与正式环境隔离，loopback 请求不会继承外部 HTTP 代理。完整 broker 集成与会话回归的外层上限为 240 秒；这是整个测试套件的预算，不是放宽单次页面请求。曾有一次发布预跑在 120 秒外层预算处终止，该预跑不作为通过证据。

测试临时目录使用系统临时位置，避免深层克隆路径挤占 Windows 文件名长度预算。全文文档和完整取证格式自测分别有 300 秒、600 秒的整组上限，保留全部正例与负例，不改变正式网页操作的超时。

## 现场验收和剩余边界

正式工具加载及现场核验已在维护窗口完成，保留 Edge、原页面、原读取断点和恢复计数。配方热加载后在原 X 页面核对了来源；后续原任务页面的 `/info` 和小范围正文读取也已通过。桥接器重载后连接、预检和队列就绪，既有待交付记录保持挂起，没有为测试发送新接单或交付消息。本次源码发布不再次重载服务，不恢复暂停中的调查。

上述现场核验只支持这些已验证动作，不证明所有平台整段历史均读完，也不等于当前版本所有平台连续三窗口验收完成。历史版本的 B 站三窗口、网易云点击和 X 拼图验收仍属于历史证据，不能移作新版全部场景的通过证明。

Windows Computer Use 原生网址识别问题没有被本仓库修复。普通、特殊及专项背调使用获准 CDP 入口，不将 CUA 作为前置检查；明确的安全或权限拒绝仍遵守其实际停止范围。浏览器单页截图超时的全部底层原因也没有得到证明。

旧两次会话回归缺少分阶段日志，不能唯一确认历史首因。已复现进程启动延迟耗尽旧 4 秒总预算的失败模式，并完成有界预算和清理回归修复。

另一台物理机器仍需重新安装、登录和授权，并按 `docs/INSTALL.md` 验证真实页面、飞书访问及用户可见交付。离线 PASS 不替代新机器现场验收；包中没有复制已授权账号或历史任务状态。
